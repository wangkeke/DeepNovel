# 宫廷 / 权谋内廷常识（词条）

- **核心定义**：古代帝王后宫体系，是皇权在私域的延伸，以妃嫔位份、子嗣数量、恩宠程度为核心生存资源，围绕皇帝、皇后、外戚与朝堂展开的权力博弈场。
- **等级森严**：皇后→皇贵妃→贵妃→妃→嫔→贵人→常在→答应→官女子，每级升降均涉及礼制、俸禄与宫权。
- **子嗣至上**：“母以子贵” 是铁律，无子嗣的妃嫔极易失势；诞下皇子可直接改变命运，公主次之。
- **门禁森严**：各宫院有侍卫、掌事太监与宫女管辖；低位者不得随意进入高位宫室；冷宫 / 废院与世隔绝。
- **信息管制**：消息经内务府与太监传递，私自传递外朝消息属大罪；“情报网” 是核心竞争力。
- **权力中心**: 养心殿（皇帝居所）、坤宁宫（皇后居所）、各宫院（妃嫔居所）、御花园（公开交际区）。
- **边缘区域**: 冷宫（废妃囚禁地）、杂役院（宫人住地）、御膳房 / 太医院 / 内务府（关键信息枢纽）。
- **内外之分**：内廷与外朝、命妇与外官往往物理与信息隔离；跨区联络须通过中性渠道（医药、贡品、修缮、仆役流转等），禁止妃子随便外朝议政 unless 设定明确破格且付代价。
- **名分与言路**：位份、谱牒、玉碟类记录决定话术空间；越级告状或面圣须合礼制或特殊契机。
- **派系寄生**：总管、嬷嬷、女官常为上层意志的末梢；整主角的多为「棋子+保护伞」结构，非单机一位娘娘。
- **把柄与交换**：恩惠常伴人情债与站队；情报多来自闲话、拜帖、药物与膳饮链条，而非御书房逛街。
