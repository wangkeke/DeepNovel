# DeepNovel 题材事件词典 — 设计与内容文档

> 本文档说明题材事件词典的定位、数据结构、完整内容，以及如何集成进创作流程。
> 不包含实现代码，只说明"改成什么样"。

---

## 一、定位与作用

题材事件词典是独立于骨骼库的"题材知识层"，解决两个问题：

**问题一：没有范文骨骼时，自由创作缺乏题材语感**
纯自由创作模式下，模型只知道"用什么类型的逻辑链"，不知道"这个类型在这个题材里通常用什么具体情节表达"。古代权谋的"间接施压型"在该题材里应该表现为"参与党争"或"上疏弹劾"，而不是通用的"被施压"。

**问题二：有骨骼时，骨骼的结构规律缺乏题材细节填充**
骨骼告诉模型"第3个节点是多源汇聚型施压"，但不告诉它"在玄幻修仙题材里，多源汇聚通常表现为宗门追杀+天才压制+秘境竞争同时出现"。

**注入方式：**
- 有骨骼时：题材词典作为"补充参考"，权重低于骨骼
- 无骨骼时：题材词典作为"基础框架"，指导 path_gen 生成有题材语感的节点路径

---

## 二、数据结构设计

每个题材一个词典条目，包含四个字段：

```
题材名称
  ├── 核心情节单元（按施压/破局分类的具体事件列表）
  ├── 常见节点序列（典型的故事弧模板，3-5种）
  ├── 题材禁忌（这个题材读者最反感的情节处理方式）
  └── 题材语感词（高频出现的场景、道具、称谓，让文字有题材气质）
```

## 四、集成进创作流程的方式

### 4.1 存储位置

新建文件 `knowledge/genre_dict.py`，以 Python dict 形式存储所有题材词典。不存数据库，因为内容固定不需要检索，直接 `import` 使用。

```
knowledge/
  __init__.py
  genre_dict.py     ← 所有题材词典
  genre_matcher.py  ← 题材匹配函数（用户输入"玄幻逆袭"匹配到"玄幻修仙"）
```

### 4.2 题材匹配逻辑

用户输入的 `genre_request` 往往是模糊的（"玄幻逆袭"、"古代言情权谋"），需要匹配到词典的标准题材名。

匹配策略：关键词命中优先，命中多个题材时取分数最高的，允许组合（"古代权谋"+"情侣日常"同时注入）。

**匹配关键词表：**
```
玄幻修仙：玄幻、修仙、修真、仙侠、炼气、筑基、宗门、灵根
重生穿越：重生、穿越、系统、前世、重来、穿书、金手指
悬疑推理：悬疑、推理、侦探、案件、凶手、密室、破案
都市职场：都市、职场、创业、霸总（兼容）、现代商战
末日科幻：末日、丧尸、科幻、异变、求生、废土
民国年代：民国、年代、旧上海、抗战、解放前
恐怖灵异：恐怖、灵异、鬼怪、民俗、阴阳
古代权谋：古代、权谋、宫斗、朝堂、皇权
校园：校园、青春、高中、大学、学生
家庭：家庭、亲情、婆媳、家族
婚礼：婚礼、婚姻、结婚
情侣日常：甜宠、日常、恋爱、情侣
霸总：霸总、总裁、商战（现代）
```

### 4.3 注入 path_gen 的 Prompt 片段

这是题材词典的核心输出，直接补充进 `PATH_GEN_USER_TEMPLATE`：

```
## 题材事件参考（{weight_description_genre}）

当前题材：{genre_name}

适合本题材的施压事件（可选用，不强制）：
{pressure_events}

适合本题材的破局事件（可选用，不强制）：
{resolution_events}

本题材常见节点序列参考：
{node_sequence_templates}

本题材禁忌（避免出现）：
{genre_taboos}

题材语感词（让节点描述有题材质感）：
{genre_keywords}

注意：以上仅为题材参考，骨骼结构优先于题材词典。
      在没有骨骼时，题材词典作为节点规划的主要依据。
```

**注入时机：**
- 有骨骼：`weight_description_genre = "适当参考，以骨骼逻辑链为主"`
- 无骨骼（自由创作）：`weight_description_genre = "重要参考，以此为节点规划基础"`

### 4.4 注入 expand1 的 Prompt 补充

expand1 做 3W1H 分析时，也注入题材施压/破局事件作为参考，帮助模型选择更有题材感的具体事件：

```
## 题材事件参考
本节点施压链类型为"{pressure_chain_type}"，
在{genre_name}题材中，常见的对应事件有：{matched_pressure_events}
请优先从以上事件中选择，或参考其模式创造新的题材合适的事件。
```
