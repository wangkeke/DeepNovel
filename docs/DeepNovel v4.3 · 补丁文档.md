# DeepNovel v4.3 · 补丁文档
## 外部关系驱动事件 × 角色能力体系

> **文档定位**：本文档是对 v4.3 终版架构文档的补丁，
> 覆盖两处之前未完整设计的内容：
> 1. World Tick 补充角色关系扫描层（支持外部关系驱动事件）
> 2. 角色卡新增 capabilities 字段（金手指/武功/特质/标志物）
> 及其对 iceberg_deduction 的连带修改。
> 合并时，以本文档为准覆盖 v4.3 终版文档的对应部分。

## 一、问题诊断

### 1.1 当前 World Tick 的盲区

当前 World Tick 只有一个扫描维度——**势力层面**。

它能感知到"哪股势力此刻处于临界状态并不得不行动"，
但感知不到"角色关系层面的世界"：

```
仇家主动设局    → 弱支持
                  high targeting_degree 的仇恨不会被主动扫描
                  只能通过 independent_agenda 被动触发

挡路者阻碍      → 部分支持
                  势力层面的对立可以触发
                  个人层面的阻碍几乎不被感知

恩人索恩情      → 基本不支持
                  benefactor_debt 存在于 entity_cards
                  但完全没有流入 event_chain_gen

盟友背叛        → 基本不支持
                  "薄情寡恩"等 innate_traits + 压力状态
                  没有被扫描为潜在的事件驱动力
```

**根本原因**（cursor 诊断准确）：
entity_cards 里存着 targeting_degree、ebd_to_protagonist、ebd_bond_kind，
但这些数据没有流入 event_chain_gen 的提示词。
entity_cards → event_chain_gen 这条线是断的。

### 1.2 角色卡缺失能力体系

当前角色卡（protagonist_card / entity_card）没有记录：
- 武功体系/所修大道/当前境界
- 标志性随身物品（佩剑、工具包、法器）
- 金手指（类型、核心能力、代价与限制、当前状态）
- 特殊体质或先天特质（痛觉缺失、过目不忘等）

这导致四维资源推导不完整——金手指和特殊能力本质上是信息差或
特殊地理/时间优势的极端形式，不写入档案，推导引擎就会视而不见。

**金手指不是主角专属**：反派可以有"气运观测"，
配角可以有"窃听心声"，NPC 可以有"随身空间"——
任何影响博弈格局的实体能力都必须在档案中记录。

## 二、修订一：World Tick 补充角色关系扫描层

### 修订位置

v4.3 终版文档 → PROMPT 7 `event_chain_gen` → 第一步 World Tick

### 修订内容

将 World Tick 从单一扫描扩展为两个并行扫描：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第一步：World Tick——物理隔离主角
（两个并行扫描，任一或两个均可成为 Fated Collision 的世界议程输入）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

在这一步，主角不存在。
世界以两个平行维度自转，分别从势力格局和角色关系中
推导此刻正在发生的紧迫力量。

━━━━━━━━━━━━━━━━━━
扫描维度一：势力层面（现有，保持不变）
━━━━━━━━━━━━━━━━━━

从 world_archive 中，找出此刻处于最紧张节点的势力：

处境分析：
- 哪股势力的 current_status 正处于临界状态？
- 哪个角色的 independent_agenda 与当前处境产生了最强烈的摩擦？
- 是否有角色的 emotional_capacity 已接近透支临界点？

性格投射（从 innate_traits 推导，不套模板）：
给定他的先天性格和当前处境，他最在意的东西受到了什么威胁或
看到了什么机会？他无法不做的事是什么？

输出：势力层面此刻自转的紧迫力量（来自档案推导）。

━━━━━━━━━━━━━━━━━━
扫描维度二：角色关系层面（新增）
━━━━━━━━━━━━━━━━━━

从 entity_cards 中，扫描与主角存在强关系的所有角色，
分三类并行推导：

【A类：仇敌与阻路者（高 targeting_degree 角色）】

读取 targeting_degree >= 阈值（建议 60）的角色，
对每个角色独立推导：

- 给定其 innate_traits + 当前处境 + emotional_capacity：
  他此刻是否有能力、有动机、有时机对主角发动攻击或设局？
- 给定其 ebd_bond_kind（blood_feud / rivalry_jealousy 等）：
  仇恨或嫉妒的强度是否已积累到需要行动的临界点？
- 他此刻"无法不做的事"是什么？

可能生成的事件驱动力：
→ 仇家设局（借他人之手陷害）
→ 正面打压（利用职权/资源直接碾压）
→ 挡路碾压（主角的路与他的利益空间产生了零和冲突）

【B类：恩情持有者（benefactor_debt / 高正向 ebd 角色）】

读取 ebd_bond_kind = benefactor_debt 或
ebd_to_protagonist >= 高正向阈值（建议 60）的角色，
对每个角色独立推导：

- 给定其当前处境：他此刻是否面临需要主角帮助的困境？
- 给定其 innate_traits：他会以什么方式寻求帮助？
  （直接开口/暗示/让第三方传话/陷入困境等待主角发现）
- 他此刻"无法不做的事"是什么？

可能生成的事件驱动力：
→ 恩人来索恩情（直接或间接）
→ 友人/家人陷入困境触发主角介入
→ 旧日盟友因主角的崛起而产生新的利益纠葛

【C类：潜在背叛者（性格底色与当前压力的临界点）】

读取满足以下条件之一的角色：
- innate_traits 中含有"薄情寡恩"/"见风使舵"/"极度功利"等性格标签
- ebd_bond_kind = alliance_interest（利益联盟，非情感联盟）
- emotional_capacity 已降至低阈值（建议 <= 30）

对每个符合条件的角色推导：
- 他此刻面临的利益诱惑或生存压力有多大？
- 给定他的性格底色，这个压力是否已经超过了他对主角情感约束的上限？
- 他此刻"无法不做的事"是什么？

可能生成的事件驱动力：
→ 盟友在威逼利诱下出卖主角
→ 表面上的恩人为了更大利益反咬一口
→ 中间人在两方压力下被迫选边

⚠️ C类特别说明：
性格底色（innate_traits）是终生不改的出厂设置。
当外部压力（targeting_degree / 利益诱惑 / emotional_capacity 透支）
足够大时，性格底色会覆盖 ebd 的情感约束——
"薄情寡恩"的人在面临足够大的利益损失时，
即使 ebd_to_protagonist = 70（感情深厚），也可能选择背叛。
这不是角色变了，这是他一直以来的真实底色在极端压力下的显现。

━━━━━━━━━━━━━━━━━━
两个扫描维度的输出整合
━━━━━━━━━━━━━━━━━━

两个维度可以各自独立成为 Fated Collision 的世界议程，
也可以在同一个事件中交织（如：仇家设局恰好利用了恩人的困境来做饵）。

当两个维度都有强驱动力时，优先选择与下一个锚点的
arrival_condition 更接近的那个维度作为主要世界议程。

输出：N个并行的世界议程（来自势力层面 + 角色关系层面的合并推导）
```

## 三、修订二：角色卡新增 capabilities 字段

### 修订位置

v4.3 终版文档 → PROMPT 3 `protagonist_card` 及 `entity_card`（配角卡）

### 修订内容

在现有角色卡输出规范末尾追加 `capabilities` 字段：

```json
"capabilities": {
  "combat_skills": [
    {
      "skill_name": "功法/武功/流派名称",
      "system": "所属体系（如：儒家剑道/佛门金身/古武暗劲）",
      "current_level": "当前境界或熟练程度",
      "signature_technique": "标志性招式或用法（可选）"
    }
  ],
  "dao_foundation": "所修大道/核心法则（修仙/玄幻文适用；现实文填null）",
  "signature_items": [
    {
      "item_id": "物品唯一标识",
      "item_name": "物品名称（如：佩剑「霜降」/工具包/令牌）",
      "item_function": "实际功能或象征意义",
      "concealment": "是否刻意隐藏（是/否）",
      "current_status": "在身/丢失/已损毁/被夺"
    }
  ],
  "golden_finger": {
    "has_golden_finger": true/false,
    "gf_type": "金手指类型（参考下方六大类型；无则填null）",
    "core_ability": "核心能力的具体描述",
    "activation_condition": "触发或使用条件（如：每天限用一次/必须处于死亡威胁下）",
    "cost_and_limit": "代价与限制（这是戏剧张力的来源，必须真实存在）",
    "exposure_risk": "一旦暴露会引发什么后果（是否构成冰山暗流）",
    "current_state": "当前积累程度/剩余次数/是否已激活"
  },
  "unique_traits": [
    {
      "trait_name": "特质名称（如：痛觉缺失/过目不忘/天生镇魂体）",
      "trait_effect": "实际效果描述",
      "double_edge": "负面效应或代价（特质必须有代价，否则是作弊）"
    }
  ]
}
```

### 金手指六大类型参考（供模型分类使用）

```
信息降维类：重生/穿书先知、鉴定眼/万物词条、读心术/窃听、死亡回档
规则豁免类：熟练度面板、等价交换/献祭系统、无限吞噬/掠夺
绝对资源类：随身空间/灵田、神豪提现/败家系统、签到/打卡
伴生外挂类：随身老爷爷/上古残魂、体内封印大妖/邪神
概念系类：概念摘取/规则篡改、言出法随/大预言术
凡人流类：极致理智、微表情大师、天生疯狂/痛觉缺失等人类特质极端化
```

### 配角卡同步说明

配角卡与主角卡同构（cursor 已实现），因此 capabilities 字段同样适用于配角。

关键配角的金手指和特质，对博弈格局的影响可能不亚于主角：
- 反派拥有"气运观测"→ 影响他对主角的评估和策略
- 关键配角拥有"窃听心声"→ 可能成为信息差博弈的核心变量

bible_update 在更新角色卡时，也需要追踪 capabilities 的状态变化：
- 金手指的 current_state 是否消耗？
- signature_items 是否丢失/损毁？
- unique_traits 的 double_edge 是否被触发？

## 四、修订三：iceberg_deduction 新增金手指暗流来源

### 修订位置

v4.3 终版文档 → PROMPT 4 `iceberg_deduction` → 第四步 冰山水面下的结构

### 修订内容

在现有暗流来源（势力 resource_claim 冲突 + 角色 independent_agenda 冲突）
的基础上，增加第三个来源检查：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━
第四步：冰山水面下的结构（补充金手指暗流检查）
━━━━━━━━━━━━━━━━━━━━━━━━━━━

在原有两个暗流来源检查完成后，增加第三个检查：

【来源三：capabilities 引发的潜伏危机】

读取主角和核心角色的 capabilities 字段，检查：

检查点A：金手指的暴露风险
  - golden_finger.exposure_risk 描述的后果，是否本身构成一条暗流？
  - 这条暗流的潜伏形式：主角在开篇中的哪个细节，可能被未来的敌人
    或觊觎者注意到，却还没有引发警觉？
  - 示例：主角有"随身空间"→ 暗流：某个古老传承者在开篇的某个细节
    中隐约感知到了主角身上的异常波动，但还未确认。

检查点B：金手指代价的积累危机
  - golden_finger.cost_and_limit 描述的代价，是否会在某个时刻爆发？
  - 等价交换系统 → 主角已经付出了X次代价，
    累积到某个节点必然触发更大的偿还。
  - 体内封印 → 封印在开篇时还很稳固，但每次使用都在消耗稳定性，
    某一章的某个关键时刻会突然失控。
  - 这条暗流在开篇中的痕迹：某个细节暗示了代价的存在，
    但读者此刻还以为只是普通描写。

检查点C：金手指与性格的悲剧张力
  - golden_finger.gf_type 和主角的 innate_traits 之间，
    是否存在天然的悲剧组合？
  - 示例：等价交换金手指 + 护短性格 
    → 必然有一天主角需要献祭他最在意的人换取力量，
    这是从开篇就注定的悲剧走向。
  - 这种张力本身就是最深的冰山——读者在开篇感受到的是"这个主角很厉害"，
    却没有意识到这种厉害本身埋下了什么。

检查点D：核心配角的 capabilities 构成的外部威胁
  - 反派或关键配角的 golden_finger / unique_traits，
    是否会在未来某个节点，对主角构成主角完全没有预见的致命威胁？
  - 这条暗流在开篇中的痕迹：反派某个不经意的细节，
    日后回头看会发现那正是他金手指的隐性显现。

【capabilities 暗流的写法原则】

capabilities 暗流的 surface_trace（水面痕迹）必须遵守双重标准：
- 对初读的读者：这只是一个普通的细节，不会引起警觉
- 对回头重读的读者：会恍然大悟"原来这里已经在说了"

禁止：让 surface_trace 太明显，导致读者第一遍就猜到金手指的秘密。
禁止：让 surface_trace 太隐晦，导致引爆时读者没有"原来如此"的快感。
```

### capabilities 暗流的 iceberg_undercurrents 输出格式

在现有格式基础上，新增 `capability_source` 字段：

```json
{
  "source": "来源描述（势力冲突/角色议程/金手指代价/金手指暴露/悲剧张力）",
  "capability_source": {
    "character_id": "涉及的角色 character_id（null 表示非 capabilities 来源）",
    "capability_field": "golden_finger / unique_traits / signature_items（null 表示非 capabilities 来源）",
    "tension_type": "暴露风险 / 代价积累 / 性格悲剧 / 外部威胁 / null"
  },
  "surface_trace": "在开篇中几乎察觉不到的痕迹",
  "estimated_emergence": "大致在哪个阶段浮出水面"
}
```

## 五、修订四：bible_update 新增 capabilities 状态追踪

### 修订位置

v4.3 终版文档 → PROMPT 13 `bible_update` → 角色状态回写

### 修订内容

在现有角色状态回写中，新增 capabilities 状态追踪：

```
【capabilities 状态追踪（新增）】

检查本章写作内容，判断以下 capabilities 字段是否需要更新：

golden_finger.current_state：
  - 本章是否使用了金手指？current_state 如何变化？
  - 本章是否触发了 cost_and_limit 中描述的代价？

signature_items：
  - 本章是否有物品丢失/损毁/被夺/被使用？
  - current_status 是否需要更新？

unique_traits 的 double_edge：
  - 本章是否触发了某个特质的负面效应？
  - 如果触发，相关角色的 emotional_capacity 是否应当额外消耗？

capabilities 暗流进度：
  - 本章是否有任何情节使某条 capabilities 暗流更接近浮出水面？
  - 如果是，在 karmic_ledger 中更新对应伏笔的 estimated_payoff。
```

## 六、数据流向补充

以下是本补丁新增的数据流向，需要在 v4.3 终版文档的流向图中追加：

```
entity_cards（targeting_degree + ebd_to_protagonist + ebd_bond_kind）
  └─ 角色关系数据 ───────────────────────────→ event_chain_gen
                                              （World Tick 扫描维度二）

capabilities（主角卡 + 配角卡）
  └─ golden_finger + unique_traits ─────────→ iceberg_deduction
                                              （第四步 capabilities 暗流）
  └─ 全量 capabilities 字段 ────────────────→ event_chain_gen
                                              （四维资源推导的完整输入）
  └─ 全量 capabilities 字段 ────────────────→ path_gen
                                              （叙事路径中的能力使用参考）
  └─ capabilities_delta ←───────────────────── bible_update（每章回写）
```

## 七、设计决策记录

### 7.1 为什么不单独维护"人际关系"字段？

targeting_degree + ebd_to_protagonist + ebd_bond_kind 已经覆盖了
传统"人际关系列表"的所有功能，而且更活跃——
静态的"师徒关系"标签永远不会变，
但 ebd_to_protagonist 会随剧情动态变化，
targeting_degree 会随利益冲突升级或降级。

需要做的只有一件事：**把这些字段注入 World Tick 扫描**。
字段已经存在，缺的只是数据流的连接。

### 7.2 为什么金手指必须有代价？

从白皮书的资源竞争逻辑来看：无代价的金手指打破了资源守恒定律，
会让世界的博弈失去张力，其他角色的独立意志变得无意义。

从叙事角度来看：代价是金手指的戏剧性来源。
"等价交换 + 护短性格"这个组合本身就是一个完整的悲剧引擎——
主角越强大，他将失去的东西就越珍贵，这才是让读者无法放下书的东西。

### 7.3 capabilities 暗流为什么要遵守"双重标准"？

伏笔的价值在于引爆时的"原来如此"——读者回头重读时，
发现开篇的那个细节早就在说这件事了。

如果 surface_trace 太明显，第一遍就被猜到，引爆时没有震撼感。
如果 surface_trace 太隐晦，引爆时读者没有共鸣，
只会觉得"这是临时写的，没有铺垫"。

双重标准确保伏笔在两次阅读中都有价值。

## 附加说明：

### 金手指分类

第一类：信息降维类（认知霸权）
这是权谋、悬疑、宫斗和高智商修仙文中最顶级的金手指。它不加攻击力，只给信息差，极度考验主角的心智。
重生/穿越/穿书（先知先觉）：
核心爽点：拥有未来十几年的宏观记忆或原著上帝视角，提前截胡机缘，避开死局。
系统限制/代价：蝴蝶效应。主角一旦改变大势，原有的记忆就会失效；且必须对抗原著主角不可理喻的“天道光环”。
万物隐藏词条（鉴定眼/提示框）：
核心爽点：能看到万事万物的隐藏属性、弱点或他人机缘（例：看出废剑是上古神器，看出反派功法的罩门）。
系统限制/代价：词条只给信息，不给战力。看到了破绽，如果自身实力不够，依然需要靠极致的设局（借刀杀人）去利用这个信息。
读心术 / 窃听心声：
核心爽点：听到上位者、绿茶、伪善者的真实想法，制造极强的反差萌或信息差反杀。
系统限制/代价：通常有次数限制（一天一次），或者会听到极其恐怖/恶心的真相导致精神污染（San值下降）。
死亡回档（时间循环）：
核心爽点：通过不断死亡试错，拼凑出唯一完美的破局路线（《明日边缘》《从零开始的异世界生活》）。
系统限制/代价：极度的精神折磨。每一次死亡的痛觉都是真实的，极其考验主角的“精神阈值”和“情绪控制力”。
📈 第二类：规则豁免类（肝帝与天道漏洞）
这是升级流、修仙、武侠中最王道的金手指，主打“努力必定有回报”，打破阶级固化。
熟练度面板（天道酬勤）：
核心爽点：没有资质瓶颈！挥剑一万次，必定升级。将枯燥的修炼具象化为进度条，只要肝不死，就往死里肝。
系统限制/代价：依然需要大量的时间和基础资源（如食物、灵气）。主角必须在底层疯狂苟住，极度需要隐忍。
等价交换 / 献祭系统：
核心爽点：可以用寿元、情感、仇人的灵魂甚至自己的器官，献祭换取极其恐怖的修为或禁忌物品。
系统限制/代价：极致的马基雅维利主义。主角会在一次次交易中逐渐失去人性，变得冷血，面临“最终变成怪物”的危机。
无限吞噬 / 掠夺：
核心爽点：杀敌不仅能爆装备，还能直接吞噬对方的修为、血脉和天赋（杀人放火受招安）。
系统限制/代价：吞噬过多会导致体内真气驳杂、异种血脉反噬，或者继承死者的无尽怨念与业力（惹来更高阶敌人的追杀）。
🎒 第三类：绝对资源类（底气与底牌）
适合末日、种田、都市神豪，主打“别人在挨饿，我在吃火锅”的反差爽感。
随身空间 / 灵田：
核心爽点：拥有一个绝对安全的私人小世界，可以无限储物，或者在里面种出极品草药（时间流速不同）。
系统限制/代价：一旦暴露，就是全天下追杀的“怀璧其罪”。主角必须极度谨慎，伪装身份去黑市销赃。
神豪提现 / 败家系统：
核心爽点：花钱就能变强，或者拥有无尽的世俗财富，用资本降维打击势利眼和傲慢的财阀。
系统限制/代价：系统的钱往往只能花在别人/特定任务上，主角自己反而过得紧巴巴；或者高调炫富会引来真刀真枪的黑恶势力绑架。
签到 / 打卡系统：
核心爽点：在特定极度危险或特殊的地方（如：魔尊封印地、死牢）签到，获得远古传承。
系统限制/代价：为了签到，主角必须苟在极其枯燥/危险的地方几十年，或者被迫冒死潜入禁地。
👻 第四类：伴生外挂类（双人相声与代打）
适合需要世界观解说、或者跨阶级对抗的玄幻/灵异文。
随身老爷爷 / 上古残魂：
核心爽点：拥有一个活了上万年的百科全书，提供顶级功法和见识，关键时刻还能“代打”。
系统限制/代价：残魂极度虚弱，每次代打都会面临魂飞魄散的危险；且残魂往往背负着惊天血仇，主角被迫继承极其恐怖的宿敌。
体内封印大妖 / 邪神：
核心爽点：体内住着一个怪物（如鸣人与九尾，宿傩与虎杖）。借用邪神力量可以瞬间越级秒杀一切。
系统限制/代价：伴随着极度的失控风险。每次借用力量，身体的掌控权都会被剥夺一分，随时可能彻底魔化杀光身边的盟友。
🎭 第五类：概念系/因果律类（脑洞极客流）
这是近年来极火的创新流派，适合规则怪谈、诡秘流、脑洞文。
概念摘取 / 规则篡改：
核心爽点：把物理概念当成物品剥夺（比如剥夺长剑的“锋利”加在树枝上；剥夺敌人的“视觉”）。
系统限制/代价：极其消耗精神力，且通常需要极度苛刻的前置触发条件（如：必须让对方先回答一个问题）。
言出法随 / 大预言术：
核心爽点：说出来的话，只要符合某种逻辑，就会在现实中灵验（比如乌鸦嘴）。
系统限制/代价：反噬极大。改变多大的因果，就要承受多大的天谴。
👤 第六类：“没有外挂”的极致凡人流（凡人逆袭）
真正的神作，往往属于这一类。它把主角自身的某种【先天性格】强化到了金手指的级别。
极致的某种人类特质：
【绝对理智】：如同天生没有情感波动的机器，免疫一切魅惑、心理战和精神攻击，永远能在0.1秒内算出最优解。
【过目不忘/微表情大师】：能记住看过的每一个文字、每一条街道，能通过面部肌肉抽动判断对方是否撒谎（《神探夏洛克》《白夜追凶》）。
【天生痛觉缺失/疯狂】：打架不要命，以伤换伤，用极致的狠辣和反社会人格的疯狂，把高高在上的修仙者生生吓破胆！
