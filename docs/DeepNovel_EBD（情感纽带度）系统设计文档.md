# EBD（情感纽带度）系统设计文档

> **适用系统**：DeepNovel 叙事引擎  
> **版本**：v1.2  
> **关联模块**：`core_cast_gen_node` · `event_chain_gen_node` · `bible_update_node` · `expand1_node` · `entity_cards`(DB)

---

## 一、设计目标

| 问题 | 现象 | EBD 的解法 |
|---|---|---|
| 人物关系平面化 | 配角永远是"帮手"或"障碍"，无中间态 | 用连续数值描述关系的当前温度 |
| 情感弧线缺失 | 爱恨转折突兀，前后文不呼应 | 阈值触发"关系转折标记"，强制写出过渡场景 |
| LLM 行为逻辑矛盾 | 敌对角色突然帮忙，盟友无缘置于危险 | 将 EBD 硬编码为行为约束注入 Prompt |
| 情感数据不持久 | 每章情感状态从零开始，角色没有"记忆" | 存 DB，跨章节持久化 |

---

## 二、核心模型：双极轴量化

### 2.1 数轴定义

```
-100          -80          -60          -30          0          +30          +60          +80          +100
 │─────────────┼────────────┼────────────┼───────────┼───────────┼────────────┼────────────┼─────────────│
 执念对立        强烈敌意      明显敌视      轻度排斥     中性陌生     轻度好感      深度信任      强烈依存        生死羁绊
```

- **正值（0 ~ +100）**：正向情感驱动——主动保护、传递利益、冒险相助的倾向
- **负值（-100 ~ 0）**：负向情感驱动——主动阻碍、传递伤害、伺机报复的倾向
- **绝对值**：情感强度——越接近 ±100，行为越不受理性利益控制

### 2.2 情感类型标签（附加语义）

数值描述强度，**类型标签**描述质感，两者独立：

| EBD 区间 | 正向类型示例 | 负向类型示例 |
|---|---|---|
| ±90 ~ ±100 | 生死恋情 / 绝对效忠 / 灵魂挚友 | 执念仇杀 / 病态占有 / 血债复仇 |
| ±60 ~ ±89 | 深度信任 / 师徒情义 / 恩情难忘 | 强烈仇恨 / 嫉妒裂变 / 利益死敌 |
| ±30 ~ ±59 | 同盟好感 / 同情认可 / 暂时伙伴 | 明显敌视 / 防范警惕 / 利用关系 |
| ±1 ~ ±29 | 善意接触 / 路人正缘 | 轻微排斥 / 不信任 |
| 0 | 陌生 / 无情感联接 | — |

**字段规范**（存入 entity_cards）：
```json
{
  "ebd_to_protagonist": -53,
  "ebd_type": "利益碾压·蔑视",
  "ebd_note": "掌控冷宫物资，视主角为砧板上的鱼肉"
}
```

### 2.3 非对称性（核心设计）

A 对 B 的 EBD 与 B 对 A 的 EBD **完全独立**，分别存储：

```
主角 → 小桃：EBD +20（试探阶段的善意）
小桃 → 主角：EBD +33（收到帮助后的感激，比主角的好感更高）
```

这是现实人际关系的本质——感情投入永远不对等。

### 2.4 关系种类（`ebd_bond_kind`）与「度」的力度边界

全局 **EBD 数值**仍表示「对该角色的情感强度与驱动方向（正/负）」；**同分不同戏**由 **`ebd_bond_kind`（关系大类）** 界定：**在相同 EBD 区间下，不同关系种类对应不同的「可写上限、慎用行为、禁止行为」**，避免把系统理解成「见到主角就爱到失控、恨到降智」的卡通开关。

**`ebd_bond_kind` 建议取值**（存 `entity_cards`，与 `ebd_type` 细标签并存；`ebd_type` 可写得更具体，如「同窗友情·欠一顿酒」）：

| 取值 | 含义 |
|---|---|
| `friendship` | 友情 / 同道 / 义气 |
| `romance` | 爱情或明确单向爱慕（含未表白阶段） |
| `family` | 亲情 / 拟亲属（师门如父如兄等归入此类或单独扩展） |
| `rivalry_jealousy` | 竞争、嫉妒、同行相轻（灰区，可偏正或偏负） |
| `benefactor_debt` | 恩情、师徒承袭、救命债 |
| `alliance_interest` | 利益同盟、被迫合作、有条件的站队 |
| `contempt_instrumental` | 蔑视、工具化、阶层碾压（多对应负向或近 0） |
| `blood_feud` | 血债、族恨、不可调解的结构性敌对 |

**力度边界原则（实现 Prompt 与审读时的共同标准）**：

- **边界回答的是**：在**当前剧情已给出的信息、利害、场面**下，这种关系 **允许写到多深**、**哪些写法算越级**（例如友情 +60 不宜无理由写性意味独占；爱情 +30 不宜写不求铺垫的当众以死明志）。
- **边界不回答的是**：「这一章必须出场帮主角」——是否行动取决于 **是否知情、是否在场、代价是否可承受**（见 §2.5）。

**分种类 × EBD 档位（叙事力度参考表，可随题材在落地 Prompt 中微调）**

*正值区间（示意）；负向见下表。*

| EBD（约） | 友情 `friendship` | 爱情 `romance` | 亲情 `family` |
|---:|---|---|---|
| +1 ~ +29 | 道义上顺手帮小忙；不写独占/吃醋 | 好感/暗恋：小动作、多看你一眼；不写双向山盟 | 庇护欲萌芽；可写唠叨、偏心，不写为爱决裂全家 |
| +30 ~ +59 | 明确站队、两肋插刀预备；**禁止**写成恋爱排他 | 可写吃醋与表态冲动，须匹配**关系阶段与是否已知困境** | 庇护与压制并存；可写「为你好」绑架感 |
| +60 ~ +79 | 高风险义气、愿担连带责任；牺牲须符合**兄弟/同道伦理**非罗曼蒂克 | 超理性庇护**可写**，须写清爱的逻辑与**代价** | 可写代过、代罪、与家族决裂边缘；须写家族反作用力 |
| +80 ~ +100 | 生死交情；仍须**剧情触发**，非每次同框必爆发 | 生死相依；**禁止**无信息来源「凭空感知你遇难」 | 血缘级牺牲；与其它关系线冲突时须写撕裂过程 |

| EBD（约） | 竞争/嫉妒 `rivalry_jealousy` | 利益同盟 `alliance_interest` | 恩情 `benefactor_debt` |
|---:|---|---|---|
| +1 ~ +29 | 正面竞争、口头较劲 | 明码交换、互相提防的合作 | 礼貌偿还不欠身 |
| +30 ~ +59 | 可写暗中使绊子、抢功；忌写成无解血仇除非已铺垫 | 可临时加码条件、反悔须付代价 | 愿为你破例一次，要还人情债 |
| +60 ~ +79 | 可写联合外敌、毁你名节；须符合**长期嫉妒铺垫** | **随时可能反水**须外显为悬念，禁止写成无脑忠义 | 愿担大风险；动机以**恩情逻辑**为主禁止偷换为无因恋爱 |
| +80 ~ +100 | 执念化竞争（可与其他负向叠加） | 仅存共同敌人时的假盟；解除敌对即散 | 效忠可到愚忠；须写悲剧性或觉悟成本 |

*负向区间（示意）*：

| EBD（约） | 蔑视/工具化 `contempt_instrumental` | 血仇/结构性敌对 `blood_feud` | 竞争/嫉妒（负向主导）`rivalry_jealousy` |
|---:|---|---|---|
| −1 ~ −29 | 克扣、怠慢、当空气 | 冷处理、记账式敌意 | 酸、拆台、不配合 |
| −30 ~ −59 | 公开羞辱、利用规则卡你 | 主动加压、剪除羽翼 | 勾结中人、传谣、抢资源 |
| −60 ~ −79 | 要见你跌到底；表面可无表情 | 要你身败/家破的逻辑链启动 | 不顾自毁也要拉你下水（须铺垫） |
| −80 ~ −100 | 工具理性消失、羞辱也可能不顾代价 | 执念级：叙事可改走向，仍须**有因**非「见你就咬」 | 与 §3.3 执念等规则衔接 |

> **写作铁律**：上表是**许可与封顶**，不是**每章必演清单**。同一角色在不知情、不在场、被更高意志压制时，**允许「不行动」或「小动作 only」**，只要与 §2.5 一致。

### 2.5 EBD 与剧情情境绑定（倾向 + 边界，禁止脱离叙事）

EBD 用于 **辅助推送情节**（例如爱慕者在**确认主角陷入困境**且**代价可承受**时，由内而外做出加大码的举棋 → 大动作可撼动主线），**禁止**死读为「高 EBD = 只要同框就无脑护/无脑咬」。

**叙事前检（生成/扩写时逻辑自洽，可写入 expand1 / write 的隐式检查清单）**：

1. **信息**：该角色**如何得知**当前困局？（亲见、听说不实、主角求助、第三人传话）— 不知则**不得**写「立刻空降解决」。
2. **利害与成本**：行动是否**损害其既有立场/关系/任务**？必须写出**可感知代价**或**克制不行动的理由**，禁止零成本深情/零动机恨意。
3. **反应强度**：在已知 §2.4 边界内，**内在冲动 → 实际外显**可分级：仅焦虑、托人传话、迂回帮助、公开站队、赌命—须与**当前章节拍**和**事件链**对齐。
4. **合法沉默**：高负向可表现为**忍、借刀、等窗口**，不必次次当面发作；高正向亦可因**误会、家族禁令、自卑**而**退缩**，避免脸谱化。

**与「改变故事走向」的关系**：EBD **提高**某类选择在给定处境下的**合理性与可写上限**；是否采纳该选择以**事件链 / path 分支**承接（见产品路线图中的 path 层联动）。**不是**「数值到了就改剧情」，而是「数值 + 情境满足时，**允许**升格为改线动作并须回溯因果」。

### 2.6 主角感情基线：亲情 **或** 爱情至少一条；红颜 1：N；度数多号并存

为提升长篇可诉性，全书须有一条**可写厚**的主感情轴，但**不等于**必须有恋爱或必须有多角恋：

1. **主感情基线（策划铁律）**  
   **`family`（亲情，含拟亲属）** 与 **`romance`（爱情/红颜线）** 在构思阶段 **自由选择**，但 **至少落实其中一类**（可与友情、恩情等并存；仅有纯友情而无亲情且无爱情的设计 **应避免**）。  
   落地：`synopsis` 的 `family_emotion_line` / `romance_emotion_line` 不得同时为「无」或空；`core_cast` 的 `lifelong_allies` 中至少一人 `ebd_bond_kind` 为 `family` 或 `romance`。

2. **亲情线 · 多个角色 · 度数任意组合**  
   多名亲属/拟亲属各自 **`ebd_to_protagonist` 独立**：允许 **一正一负**（如慈母高正、毒父高负）、**两向皆正**、**皆负**、或夹在中间的灰色；不得以「全家必须同仇敌忾」包办叙事。

3. **爱情线 · 红颜 1：N · 单向或双向**  
   主角可与 **多名** `ebd_bond_kind: romance` 角色建立张力；**每人单独一条 EBD**，互不从众数。  
   **单向恋**：常见为「对方→主角」高正而「主角→对方」低/中（或反之），须用 §2.3 **双向独立存储** 或 **`ebd_note` / `relationship` 文案** 写清叙事锚点，禁止全员自动双向深爱。  
   **双向恋**、**暧昧未判明** 均合法，仍须 **情境绑定（§2.5）**，禁止无脑护短。

4. **与「可无恋爱」的关系**  
   若本书明确 **不写爱情**，则须用 **亲情（或等效的 family 锚点）** 满足「至少一条」；反之若家庭淡薄，则须在 `romance_emotion_line` 与同卷 `ebd_targets` 中写清爱情主轴。**禁止**亲情与爱情两条概要同时空置。

## 三、状态机变换律

### 3.1 常规演变（每章微调）

每发生一次与角色情感相关的事件，EBD 发生 **±5 ~ ±20 的微调**：

| 事件类型 | Delta 参考值 |
|---|---|
| 主角帮助该角色解困 | +10 ~ +20 |
| 主角主动出卖/利用该角色 | -15 ~ -25 |
| 主角在对方面前展现能力/价值 | +5 ~ +15 |
| 对方方面发生针对主角行为 | -8 ~ -15 |
| 双方共同经历极端处境（生死） | ±20 ~ ±40 |

### 3.2 阈值触发（关键转折）

当 EBD 跨越关键阈值时，触发**强制叙事事件**：

| 阈值跨越 | 触发效果 |
|---|---|
| 首次进入 ±30 区间 | 系统提示：本批事件须有一个明显的"关系定性场景" |
| 首次进入 ±60 区间 | 系统提示：须写出一个"关系转折标记章"，角色态度发生外显变化 |
| 首次进入 ±80 区间 | 触发"立场检测"——若为负值，强制进入`human_review_role_shift`流程 |
| 跨越 0 轴（正负互转） | 触发"爱生恨"或"恨生爱"特殊弧光节点，expand1 强制注入"裂变/愈合场景"要求 |

**说明（与 §2.4 协同）**：全局阈值默认如上；落地时可根据 `ebd_bond_kind` **微调**「须外显的章节门槛」（例如爱情线可能对 **±20~±25** 就要求态度可读，友情线可略晚；嫉妒主导负向可能在 **−25~-35** 即出现可感破坏行为）。微调规则写在工程侧配置或 Prompt，本文档保留原则即可。

### 3.3 特殊变换律

**爱生恨（Love-to-Hate）**：
```
触发条件: EBD > +60 AND 本章事件包含「背叛/欺骗/重伤/牺牲被辜负」
变化规则: 新EBD = -(旧EBD × 0.8)，类型强制切换为「仇恨/执念」
特殊标记: ebd_crack=True（裂痕系数激活，该角色EBD永久上限 ≤ +50）
```

**恨生爱（Hate-to-Love）**：
```
触发条件: EBD < -60 AND 本章事件包含「相救/绝地信任/共同生死」
变化规则: EBD += +25 ~ +40（缓慢回升），不超过 ebd_crack 上限
特殊说明: 转化过程须经历≥3个章节节点，禁止单章突变为正值
```

**执念固化（Obsession Lock）**：
```
触发条件: EBD < -80 连续维持 ≥ 5 个章节节点
效果: 该角色进入"执念模式"，其所有行为优先服从仇恨逻辑而非利益逻辑
行为约束: 在任何 expand1 中注入"该角色当前处于执念状态，不会因短期利益改变立场"
```

## 四、驱动引擎：四段式闭环

```
┌─────────────────────────────────────────────────────────────┐
│                     EBD 驱动闭环                            │
│                                                             │
│  [初始化]          [预声明]         [演算]          [注入]  │
│  core_cast_gen  →  event_chain  →  bible_update  →  expand1│
│       │               │                 │               │   │
│  设定原点EBD      标注情感节点      每章结算更新     注入行为约束│
│       │               │                 │               │   │
│  entity_cards ←───────────────── entity_cards ────────────→│
│  (DB 持久化)                      (DB 持久化)              │
└─────────────────────────────────────────────────────────────┘
```

### 4.1 第一段：初始化（`core_cast_gen_node`）

生成核心班底时，每个角色同时获得初始 EBD 锚点：

**LLM 输出 schema 扩展**：
```json
{
  "ultimate_villain": {
    "name": "皇后",
    "ebd_to_protagonist": -30,
    "ebd_bond_kind": "contempt_instrumental",
    "ebd_type": "工具利用·漠视",
    "ebd_note": "尚未正式介入，只把主角视为可消耗的棋子"
  },
  "lifelong_allies": [
    {
      "name": "小桃",
      "ebd_to_protagonist": 0,
      "ebd_bond_kind": "friendship",
      "ebd_type": "陌生人·尚未建立关系",
      "ebd_note": "第一卷结束时预计达到 +35~+45"
    }
  ]
}
```

> **设计原则**：初始 EBD 不代表"最终态"，代表"出场时的情感坐标"。角色的情感旅程从这里出发。

### 4.2 第二段：事件链预声明（`event_chain_gen_node`）

骨架生成时，影响情感的关键事件须声明 `ebd_shift`：

**事件字段扩展**：
```json
{
  "id": 8,
  "milestone_name": "以旧信为饵结识浣衣局宫女小桃",
  "ebd_shift": [
    {
      "char": "小桃",
      "ebd_bond_kind": "friendship",
      "direction": "positive",
      "delta_range": "+15~+25",
      "trigger_condition": "主角帮小桃化解当众责罚",
      "ebd_type_after": "初步信任·感激"
    }
  ]
}
```

这是**情感地图的预标注**——告知 path_gen 和 expand1 在这个里程碑附近须为情感弧留足章节容量。

### 4.3 第三段：每章演算（`bible_update_node`）

**这是 EBD"动"起来的核心引擎**。每章写完后自动执行：

**Step 1：LLM 提取情感时刻**
```
Prompt：
分析以下章节正文，找出所有影响角色对主角情感的关键时刻。
对每个时刻，输出：
{ "char": 角色名, "event_desc": 事件描述, "delta": 数值, "reason": 情感逻辑 }
仅输出有明显情感变化的角色，中性互动不需要输出。
```

**Step 2：演算新 EBD**
```python
for change in llm_output:
    char = change["char"]
    old_ebd = load_ebd_from_db(project_id, char)
    raw_new = old_ebd + change["delta"]
    
    # 应用裂痕系数上限
    if char.ebd_crack:
        raw_new = min(raw_new, 50)
    
    new_ebd = max(-100, min(100, raw_new))
    
    # 检测阈值突破
    check_threshold_triggers(old_ebd, new_ebd, char)
    
    save_ebd_to_db(project_id, char, new_ebd)
```

**Step 3：阈值触发处理**
```python
def check_threshold_triggers(old_ebd, new_ebd, char):
    # 跨越 0 轴（爱生恨 / 恨生爱）
    if old_ebd > 0 and new_ebd < 0:
        set_story_flag("love_to_hate", char)  # 下章强制写裂变场景
    if old_ebd < 0 and new_ebd > 0:
        set_story_flag("hate_to_love", char)  # 下章强制写愈合场景
    
    # 跨越 ±80（立场检测）
    if old_ebd > -80 and new_ebd <= -80:
        trigger_role_shift_review(char)       # 触发 human_review_role_shift
    
    # 进入 ±60 区间（关系转折）
    for threshold in [30, 60, 80]:
        if crosses_threshold(old_ebd, new_ebd, threshold):
            set_scene_requirement(char, f"关系定性场景（EBD跨越±{threshold}）")
```

### 4.4 第四段：注入行为约束（`expand1_node`）

每章展开分析时，从 DB 读取当前章节涉及角色的 EBD，注入 Prompt：

**注入格式（硬编码为 LLM 铁律）**：
```
【本章角色情感状态 · EBD 行为约束（铁律）】

▶ 小桃  EBD +33（初步信任·感激中段）
  行为约束：会主动传递低风险信息；若主角要求高风险配合须付出代价（情义债、秘密交换等）
  禁止：无条件冒险；无因数据全托付
  特殊：若本章有"替她挡难"类事件，EBD 可再升 +10~+15

▶ 李公公  EBD -53（利益碾压·蔑视中段）
  行为约束：会日常性刁难和施压；不会正面下死手；对主角的"聪明行为"产生警觉
  禁止：主动相助；忽视主角的明显得分行为
  特殊：若主角本章当众压制李公公，须写出其"暗中仇恨升级"的细节

[全局 EBD 铁律]
角色的对话语气、行动决策、情绪反应必须严格匹配以上 EBD 值与 §2.4 中该角色 `ebd_bond_kind` 的力度边界。
EBD < -60 的角色：一切行动服从敌意逻辑，即使表面配合也须写出暗藏的算计；**仍须满足 §2.5**（信息来源、动机、代价），禁止无因发疯。
EBD > +60 的角色：可以做出超出理性利益的庇护行为，但须消耗可感知的代价（名誉、资源、关系）；**禁止在未获知困境、未在场的设定下凭空全力施救**。
```

## 六、与现有系统的协同

### 6.1 与「针对度」的正交关系

| 维度 | 针对度（Threat Level） | 情感纽带度（EBD） |
|---|---|---|
| 衡量对象 | 反派对主角的「威胁行为强度」 | 任意角色对主角的「情感驱动方向」 |
| 单位 | 0% ~ 100%，单向 | -100 ~ +100，双向 |
| 变化触发 | 主角的成长/崛起事件 | 双向情感互动事件 |
| 行为影响 | 反派的「绞杀烈度」 | 所有角色的「行为倾向」 |

**组合效果示例**：
- `针对度 85% + EBD -90（执念）` → 不死不休的终极反派，超越利益判断的绝杀模式
- `针对度 20% + EBD -70（仇恨）` → 暗中积蓄实力的隐忍者，在等待时机
- `针对度 60% + EBD +40（被迫合作）` → 主角的强制盟友，随时可能反水

### 6.2 与「分卷规划」的联动

`story_arc_plan_node` 的分卷规划须声明各卷的 EBD 预期终态：

```json
{
  "volume_index": 0,
  "volume_name": "冷宫寒夜",
  "ebd_targets": [
    { "char": "小桃", "ebd_bond_kind": "friendship", "ebd_end": "+35~+45", "note": "本卷结束时须建立稳定信任通道" },
    { "char": "李公公", "ebd_bond_kind": "contempt_instrumental", "ebd_end": "-60~-70", "note": "主角在本卷末对其完成反制，仇值升级" }
  ]
}
```

这让 path_gen 知道本批事件结束时各角色应当到达的情感坐标，从而在剧情节点分配上为情感弧留出容量。

### 6.3 与「高阶蔑视名单」的协同

高阶蔑视名单（untouchable_characters）的"可降维波及"规则，与 EBD 结合后更精确：

```
高位角色对主角的 EBD = -10（漠视·不在意）时：
  → 降维波及 = 随手碾压，不带个人情绪，只是路过顺手为之
  → 禁止：自降身份专门针对主角

高位角色对主角的 EBD = -50（厌恶·略感碍眼）时：
  → 可以有余波，但须是"议程转移"或"代理人出手"
  → 禁止：亲自长线追杀
```

## 七、Prompt 工程规范

### 7.1 EBD 行为约束模板

文件位置：`prompts/common/emotional_bond_doctrine.py`

```python
def build_ebd_constraint(char_ebd_list: list[dict]) -> str:
    """
    输入: [{"name": "小桃", "ebd": 33, "ebd_bond_kind": "friendship",
             "ebd_type": "初步信任", "special_flags": []}, ...]
    输出: 注入 expand1 的 EBD 行为约束文本

    落地时：在数值区间规则之上，叠 §2.4 中对应 ebd_bond_kind 的力度边界摘要；
    并注入 §2.5（信息 / 代价 / 合法沉默），避免无脑护短或无脑喊打。
    """
    lines = ["【角色情感纽带度 · 行为约束（铁律）】\n"]
    for c in char_ebd_list:
        ebd = c["ebd"]
        name = c["name"]
        ebd_type = c.get("ebd_type", "")
        # bond = c.get("ebd_bond_kind", "")  # 用于选择 §2.4 子规则与 §3.2 阈值微调

        if ebd >= 80:
            rule = f"可为主角做出超理性牺牲；拒绝任何对主角不利的合谋"
        elif ebd >= 60:
            rule = f"深度信任；可提供高风险协助，但需感到主角值得这份信任"
        elif ebd >= 30:
            rule = f"友好合作；帮助须有利益对等或情义回报；不会无因冒险"
        elif ebd >= 0:
            rule = f"中性；以利益判断为主；可被收买或说服"
        elif ebd >= -30:
            rule = f"轻度排斥；不主动帮助；对主角的行动持怀疑态度"
        elif ebd >= -60:
            rule = f"明显敌视；日常性阻碍；不下死手但会累积伤害"
        elif ebd >= -80:
            rule = f"强烈仇恨；主动寻机打击；行为受仇恨逻辑主导"
        else:
            rule = f"执念对立；不受利益左右；以打倒主角为第一优先"
        
        lines.append(f"▶ {name}  EBD {ebd:+d}（{ebd_type}）\n  {rule}")
    
    lines.append(
        "\n[EBD 全局铁律] 情绪、对话、行动须与 EBD 值及 `ebd_bond_kind` 力度边界（§2.4）一致；"
        "重大行动须满足 §2.5（知情、代价、因果）。禁止人物行为与情感状态矛盾。"
    )
    return "\n".join(lines)
```
