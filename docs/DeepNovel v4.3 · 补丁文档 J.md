# DeepNovel v4.3 · 补丁文档 J
## 叙事引擎：主角能动性 × 单元剧画卷结构

> **文档定位**：本文档解决当前系统的一个根本性叙事问题：
> 主角一直处于被动应对状态（外部危机把主角推进下一个事件），
> 导致小说读起来像"被反派满地图追杀的流水账"，
> 而不是像《邪门儿》《北派盗墓笔记》《诡舍》那样
> "画卷一点点打开"的沉浸式单元剧结构。
>
> **核心修订节点**：idea_forge、event_chain_gen（Protagonist Tick）
> **不新增节点**，只修订现有节点的提示词逻辑。

---

## 一、问题的本质

### 现在的叙事结构

```
外部危机（反派行动）→ 主角被动应对 → 危机升级 → 继续被动应对
```

主角没有自己的行动意志。所有事件都是"世界打过来的拳"，
主角只能接招，永远在应对，永远在逃。

这种结构读到后期会让读者感到疲惫——
主角从未真正"活在"这个世界里，只是在被剧情追着跑。

### 好小说的叙事结构

```
主角有自己要做的事（生存逻辑 + 独立议程）
→ 他主动去做这些事
→ 在主动行动中碰到意外
→ 意外有时触碰主线真相，更多时候只是增加阅历、认识人、结仇
→ 主角抓住触碰主线的那条线继续追
→ 画卷一点点展开
```

关键差异：**危机是主角主动行动时碰到的意外，不是从天而降的追杀。**

### "派单机制"的真正含义

《邪门儿》《北派盗墓笔记》《诡舍》表面上都有"接任务"的结构，
但这个结构不是一个具象的派单堂口，而是一个抽象的逻辑自洽性：

```
主角为什么会主动卷入这些事？

《邪门儿》陈阎：
  具象：劳务市场摆摊 → 加入人间堂
  抽象：他要在城市里活下去 + 打探师父的线索
        → 找到符合自身技能的谋生方式
        → 这个谋生方式自然产生接触形形色色人和事的机会
        → 某些接触碰巧触碰主线 → 主角主动追

《北派盗墓笔记》：
  具象：接受倒斗委托
  抽象：要发扬北派 + 赚钱 → 倒斗是他的专业 → 每个墓有各自的故事

《诡舍》：
  具象：系统派发任务
  抽象：住进诡舍是生存绑定 → 完成任务才能活 → 每个任务揭开一层秘密
```

**派单机制的本质**：
主角的生存逻辑自然产生了"主动接触世界"的结构，
不是一个硬造的组织或系统。

### 任务完成不必每次都有主线碎片

这是另一个重要的修正：

```
错误认知：每个任务闭合时都必须产生主线碎片
  → 会让读者感到"太刻意"，破坏画卷感

正确认知：
  大多数任务完成后，可以只是：
    · 认识了一个人（人脉积累）
    · 结了一个仇（未来事件的种子）
    · 赚了钱活下去（生存压力的暂时缓解）
    · 熟悉了某个地方的规矩（世界观的自然展开）
  
  主线碎片只在特定任务上自然出现
  主角自己抓住这些线索去追
  读者不会每次都预期"这个任务有主线意义"
  偶尔出现的关联才会产生真正的震撼感
```

## 二、修订一：idea_forge 新增谋生逻辑字段

**修订位置**：`prompts/creation/brainwave_engine.py`
→ `BRAINWAVE_ENGINE_BODY` 的 `opening_crisis` 部分之后

**新增字段**：`survival_logic`（谋生逻辑）

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━
【谋生逻辑设计（Survival Logic）】
━━━━━━━━━━━━━━━━━━━━━━━━━━━

主角的生存逻辑是整个叙事节奏的地基。
在这里你需要回答：主角靠什么活着？

这不是一个简单的职业设定，而是一个逻辑自洽的生存结构：
  - 主角有什么技能/资源？
  - 这个世界里，这些技能/资源能通过什么方式换取生存所需？
  - 这个谋生方式会让主角自然接触到什么类型的人和事？
  - 这种接触如何与他的独立议程（查真相/复仇/续命）产生交叉？

【关键约束】
谋生方式必须从主角的性格、技能、处境中自然生长，
不能硬造一个与主角气质不符的"接单组织"。

正确示范：
  陈阎（民间灵异）：
    在老城区开纸扎店→客群自然带来除煞/平阴阳的委托
    → 无需硬造"人间堂"，纸扎店本身就是天然的信息节点和委托来源
    → 客群（丧主、道士、老城区居民）是他认识江湖的窗口

  北派盗墓传人：
    靠倒斗谋生→必须在行业内找客户和销赃渠道
    → 这个网络自然包含了各色三教九流
    → 每次下墓都是一个相对独立的"任务"

  都市职场审计实习生：
    靠薪水生存→工作本身就是接触各种财务问题的渠道
    → 每个审计项目是一个相对独立的"案子"

错误示范：
  × 主角毫无理由地加入了某个神秘组织并开始接单
  × 派单来源与主角的性格处境毫无关联
  × 谋生方式与主线任务完全隔离，读者感到人为安排
```

**新增的 `survival_logic` 输出字段**（追加到 `brainwave_formula`）：

```json
"survival_logic": {
  "how_protagonist_survives": "主角靠什么活着（一句话）",
  "natural_contact_structure": "这个谋生方式让主角自然接触到什么类型的人和事",
  "episodic_source": "相对独立的'任务/案子/委托'从哪里来（不必是正式组织，可以是口耳相传、自然发生）",
  "mainline_intersection": "这个接触结构如何与主角的独立议程（查真相/续命/复仇）产生自然交叉",
  "world_expansion_logic": "通过完成这些任务，主角的世界版图如何一点点扩大"
}
```

## 三、修订二：protagonist_card 强化独立议程字段

**修订位置**：`prompts/creation/protagonist_card.py`
→ `independent_agenda` 字段的提示词说明

**当前问题**：
`independent_agenda` 字段存在，但描述过于静态——
只说明主角"计划做什么"，没有说明主角"为什么主动去做这些事的驱动力"。

**修订内容**（在 `independent_agenda` 的生成说明中增加）：

```
【independent_agenda 的设计要求】

这个字段不只是主角的计划清单，
而是主角在没有外部事件干预时，他自己会主动去做的事。

设计时必须回答：
  1. 主角的日常行动轨迹是什么？
     （他每天/每周会主动做哪些事？不是被动应对，是主动出击）
  2. 这些主动行动来自什么内在驱动？
     （不是因为有人逼他，而是他自己认为该做）
  3. 这些主动行动与他的生存逻辑如何连接？
     （他做的事如何帮助他活下去，同时推进他的终极目标）

正确示范：
  陈阎：
    每天开店接客，借机收集老城区的阴阳消息
    每隔几天去探访一个还活着的旧日知情人
    在有能力的情况下，主动处理一些无人问津的阴差乱局
    → 这些行动不是被逼的，是他认为"该做的事"

错误示范：
  "陈阎计划找到师父死亡的真相"（这是目标，不是独立议程）
  "陈阎想要续命"（这是刚需，不是主动行动）
```

## 四、修订三：event_chain_gen 的 Protagonist Tick 重构

这是最核心的修订。

**修订位置**：`prompts/creation/event_chain_gen.py`
→ `第二步：Protagonist Tick` 部分

**当前问题**：
Protagonist Tick 主要从 `core_desire` 和 `core_fear` 推导主角需求，
导致主角永远处于"刚需驱动"状态——要么在追求最渴望的东西，要么在逃避最恐惧的东西。
这种状态下，主角永远是被动的，永远在应对极端处境。

**修订后的 Protagonist Tick**：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第二步：Protagonist Tick——主角此刻在主动做什么？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

在这一步，世界的其他力量暂时不存在。
你需要推导：主角此刻，在没有外部压力时，他自己会主动去做什么？

【优先读取 independent_agenda（主动行动议程）】

从 protagonist_archive.independent_agenda 中读取：
主角在当前阶段会主动做哪些事？

这些主动行动是 Protagonist Tick 的首要输入，
而不是从 core_desire 或 core_fear 倒推的被动刚需。

判断此刻最自然的主动行动：
  - 他的日常行动轨迹会让他去哪里、做什么？
  - 基于上一个事件的结果，他下一步会主动做什么推进？
  - 他的独立议程中，此刻最该推进哪一项？

【何时读取 active_quest_stack 的 immediate 层】

只有当以下情况之一发生时，才优先读取刚需驱动：
  a) 主角面临生死威胁，必须立即应对
  b) 主角的最重要的人处于危险中
  c) 主角的独立议程被外力强行中断

在没有上述情况时：
  主角的主动行动（independent_agenda）优先于刚需驱动

【Protagonist Tick 的三种输出类型】

类型A：主动委托型（主角主动去做一件事，没有外部压迫）
  例：陈阎主动去老城区的某个地方打探消息
  → 这种类型下，主角是事件的发起者
  → 意外/危机是他主动行动时碰到的，不是从外部打进来的

类型B：主动调查型（主角主动追一条线索）
  例：陈阎发现了一个与师父相关的线索，主动去追
  → 有明确的调查目标，但结果未知
  → 主角是主动的，不是被逼的

类型C：被动应对型（外部压力超出主角可控范围）
  例：有人来找陈阎的麻烦，他必须应对
  → 这种类型不应该是常态
  → 在一卷中，类型C的事件不应超过总事件数的30%

【输出】

{
  "protagonist_tick_type": "A主动委托 / B主动调查 / C被动应对",
  "active_action": "主角此刻主动在做什么（来自 independent_agenda 或主动追线）",
  "action_origin": "这个主动行动来自哪里（独立议程/上一事件的线索延伸/谋生需求）",
  "passive_pressure": "如果是C类型，外部压力是什么（A/B类型填null）",
  "deepest_need": "主角此刻最在意的东西（可以是主动目标，也可以是刚需）",
  "core_principle": "主角此刻遵守的最核心生存原则"
}
```

## 五、修订四：事件的单元感设计约束

**修订位置**：`prompts/creation/event_chain_gen.py`
→ `第三步：Fated Collision` 之后，新增"事件完整性约束"

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【事件完整性约束：单元感设计】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

每个事件应该具有相对独立的完整感，类似于：
  · 一个独立的委托/案子（有起点和相对清晰的终点）
  · 一次主动探索（有明确的调查方向）
  · 一场遭遇（有前因，有结果，不是无休止的追逐）

【事件结果的三种类型（causal_output 的填写参考）】

结果类型A：闭合型（事件相对完结）
  即时果：委托完成/调查告一段落/遭遇结束
  隐藏种子：只是阅历积累，认识了某人，或结了某个仇
            → 不需要每次都是主线碎片
  注意：闭合不意味着所有问题解决，
        而是这件事本身到了一个自然的节点

结果类型B：碎片型（事件触碰主线）
  即时果：表面上的委托完成/任务结束
  隐藏种子：发现了一个与主线有关的碎片信息
            主角会主动追这条线（进入B类型的下一事件）
  注意：这种类型不应连续出现超过2次，
        否则读者会感到"每件事都有主线意义"的刻意感

结果类型C：开放型（事件制造新的驱动力）
  即时果：情况发生了变化，主角的处境改变了
  隐藏种子：下一个事件的方向由主角的independent_agenda决定
            不是由外部压力决定

【比例建议（一卷内）】
  A类型（闭合型，只有阅历积累）：≥ 50%
  B类型（触碰主线）：≈ 20-30%
  C类型（开放型）：≈ 20-30%

这个比例确保：
  · 大多数时候，主角在经营自己的江湖，世界在自然展开
  · 偶尔出现主线碎片，读者会感到惊喜而非预期
  · 事件之间不是单一的危机连续，而是有节奏的起伏
```

## 八、与角色叙事流记忆引擎（补丁I讨论稿）的关系

本补丁（单元剧画卷结构）与补丁I（角色叙事流记忆）是天然配套的：

```
单元剧画卷结构解决：
  主角为什么会主动经历这些事
  事件之间的节奏感和独立性
  画卷如何一点点展开

角色叙事流记忆解决：
  主角经历这些事之后，记忆如何沉淀
  跨事件的人物和细节如何不被遗忘
  不同角色的视角如何影响后续事件的推导
```

两者的配合逻辑：

```
主角主动去接一个委托（本补丁的A类型事件）
  → 完成委托，认识了一个人，结了一个仇（阅历积累）
  → 叙事流记忆追加："我今天帮某人做了某事，这个人叫XX，
    他欠了我一个人情，但我感觉他背后有什么没说清楚"
  → 下一次 event_chain_gen 读取主角阅历流时，
    这个人的名字和未说清楚的感觉会自然浮现
  → World Tick 扫描：这个人此刻是否在做什么会影响主角？
  → 画卷的下一层自然展开
```

## 九、设计决策记录

### 9.1 为什么不直接在系统里设计"人间堂"这样的派单组织？

具象的派单组织是特定题材的特定解法，
不是一个可以跨题材复用的架构。

抽象的谋生逻辑（`survival_logic`）才是跨题材的：
  - 民间灵异：纸扎店客群自然带来委托
  - 都市职场：每个审计项目是一个相对独立的"案子"
  - 盗墓探险：倒斗客户是天然的"派单方"
  - 玄幻修仙：宗门任务/散修接活/城镇委托

让模型在 idea_forge 阶段确立谋生逻辑，
然后由这个逻辑自然生长出具象的接触结构，
比直接指定"有一个派单组织"更符合这个世界的真实感。

### 9.2 为什么 Protagonist Tick 要优先读取 independent_agenda 而非刚需？

刚需（core_desire/core_fear）驱动的事件，主角永远处于极端状态。
极端状态不是常态，不能是所有事件的驱动力。

真实的人（和角色）大多数时候在做的，是"他认为该做的事"，
而不是在极端压力下被迫应对。

independent_agenda 代表的是"主角的日常能动性"——
他不需要任何外部压力，就会主动去做这些事。
这才是让主角"活起来"的关键。

### 9.3 为什么任务完成不必每次都有主线碎片？

读者对"每件事都有深意"的叙事会产生疲惫感：
如果每个任务都产生主线碎片，读者会失去惊喜，
因为他们已经在期待"这次又会发现什么"了。

大多数任务只是阅历积累，偶尔的碎片才会产生真正的震撼。
这就是《邪门儿》给人感觉"画卷慢慢展开"而非"每章都在揭秘"的原因。
