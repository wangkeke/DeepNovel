> 替代 v1 文档，以本文档为准执行。
> 核心：让模型在规划和写作时主动识别并设计六种张力形式。
> 改动范围：四个 Prompt 文件，不涉及任何执行逻辑文件。

## 一、六种张力形式定义

以下定义需要写入所有相关 Prompt，让模型理解每种张力的本质：

```
1. 信息差张力：
   不同人物持有不同信息，做出不同选择
   读者跟着一个视角，能感受到其他视角的存在
   核心：同一件事，不同的人看到的是不同的世界

2. 反转张力：
   已建立的预期被打破
   事实反转：以为是A，其实是B
   动机反转：以为是好人，其实是幕后黑手
   局势反转：以为找到了出路，其实进入了更深的死局
   核心：读者和人物共同经历"以为知道了，其实不知道"

3. 推波助澜张力：
   有人知道真相，但主动选择利用而不阻止
   这不是沉默，是有目的的不作为——用别人的愚蠢为自己服务
   区别于主动伤害：没有明显的"坏人出手"，坏事自然发生
   核心：最可怕的危险不是有人对你动手，而是有人在旁边看你走向深渊

4. 困境张力：
   主角知道真相但无法改变局势
   他看到了错误，但没有人信他；他有能力，但条件不允许
   "看着错误发生却无能为力"的无力感
   核心：知道又如何，改变不了任何事

5. 代价张力：
   每次推进都有真实的、不可逆的损失
   不只是"情节向前走"，而是"走这一步就回不了头"
   代价要具体可见：人、物、关系、时间、机会
   核心：胜利是有代价的，读者感受到危机是真实的

6. 悬念张力：
   读者感受到还有更深的真相未被揭露
   表面的谜题解决了，但更深的谜题若隐若现
   "已知的未知"——读者知道有什么不知道，但不知道是什么
   核心：不是信息的缺失，而是对信息缺失的感知
```

## 二、`prompts/creation/path_gen.py` 修改

### 在 PATH_GEN_USER_TEMPLATE 里新增"张力规划"段落

位置：插在破局方式多样化要求**之后**，节点列表输出**之前**。

```
## 张力规划（规划节点前必须完成）

好的故事路径需要多种张力形式交织，而不是单一依赖一种。
在规划这批节点之前，先完成以下张力设计：

【张力分布规划】

这批节点共 {node_count} 个，需要覆盖以下张力形式，
每种形式至少出现一次，不能全部依赖同一种：

  信息差张力：哪个节点里有人物持有不同信息，做出不同选择？
  反转张力：哪个节点安排事实/动机/局势的反转？
             反转必须有前期铺垫，不能无中生有
  推波助澜张力：哪个节点有人知情但选择利用而不阻止？
               这个人的动机是什么？他利用的是谁的什么行为？
  困境张力：哪个节点让主角陷入"知道但改变不了"的处境？
  代价张力：哪个节点的推进让主角付出不可逆的真实代价？
  悬念张力：哪个节点揭露一个假真相，同时埋下更深的悬念？

【张力节奏规划】

张力不能一直处于最高点，需要有节奏：
  建立期节点：以信息差张力和悬念张力为主，埋下后续张力的前提
  升级期节点：以困境张力和推波助澜张力为主，压力递增
  高潮节点：反转张力爆发，代价张力达到顶点
  落定期节点：悬念张力留存，为下一卷埋钩子

【局的嵌套规划】

这批节点里至少有 2 个人物在同时运行各自的局：
  每个人物的局：目的是什么、用了什么方式
  局与局的交叉：不同人物的局如何在同一场景里交织
  谁在利用谁：有没有人在利用另一个人的无知或行动
  （推波助澜是局嵌套的典型形式）

【在节点描述里体现张力】

输出节点时，one_liner 必须体现该节点的核心张力形式：

  好的 one_liner（体现推波助澜张力）：
    "主角识破算命先生是骗子，师爷也看穿了，
     但师爷选择沉而不发，任由队伍跟着走向深渊"

  差的 one_liner（只有情节）：
    "算命先生误导大家，主角无奈跟着走"
```

### 2.1 反转老套性检验（已并入 `path_gen.py` 张力规划）

在「张力分布规划」与「张力节奏规划」之间增加：

```
【反转老套性检验】（凡高潮/转折节点且含反转张力，规划前必做）
  这个反转是否是该题材最常见的套路？
    （示例：灵异——鬼屋藏人命秘密、好人其实是坏人、宝藏是假的等）

    不只揭露「是人为的」，还要揭露「人为的背后还有更深的东西」。
    读者可能猜到第一层，猜不到第二层；tension_design 须写明第二层是什么。
```

## 三、`prompts/creation/expand1.py` 修改

### 在 EXPAND1_USER_TEMPLATE 里新增"张力分析"步骤

位置：在 **3W1H 分析之前**（与 `expand1.py` 中顺序一致）。

```
【张力分析（在 3W1H 之前完成）】

本节的主要张力形式是：{tension_type}（来自 path_gen 的规划）
本节的张力设计方向：{tension_design}

基于以上，对本节做以下分析：

【推理逻辑分析】（主角察觉异常时必须完成）

主角的察觉依据必须是"身份与行为的矛盾"，不是直觉：

  对每个被主角怀疑的人物，回答以下问题：
    这个人的身份/处境预期他应该有什么反应？
    他实际的反应是什么？
    这两者之间的落差是什么？
    这个落差意味着什么？

  示例：
    身份预期：师爷是团队智囊，懂规矩，有主见
    实际反应：对算命先生的荒唐建议一言不发
    落差：一个真正的师爷不可能对明显错误的决定沉默
    意味着：他有理由不想反驳，这个理由是什么？

  禁止以下推理方式：
    ❌ "主角感觉有什么不对劲"（直觉，不是推理）
    ❌ "主角意识到情况不妙"（结论，没有过程）
    ✅ "主角注意到王老板的眼神在合同签完后第一时间看向西侧地板，
        一个刚买房的人，不会对空房子的某个角落这么在意"

  主角的推理必须是一道逻辑题：
    已知条件A：这个人的身份/处境
    已知条件B：这个人的实际行为
    矛盾：A和B不能同时成立
    结论：要么身份是假的，要么行为有隐情

【信息持有分析】（所有张力形式都需要）

本节涉及的每个人物，各自持有的信息量：
  知道什么？
  不知道什么（但其他人知道）？
  知道但选择利用或隐瞒的是什么？

特别注意：
  "选择利用而不阻止"≠ 沉默
  推波助澜者是主动的——他在用别人的错误为自己服务
  他的不作为是一种行动，要写出他的目的和算计

【张力形式专项分析】

根据本节的张力类型，补充以下分析：

如果是信息差张力：
  读者视角设定：读者>主角（悬疑）/ 读者=主角（探索）/ 读者<主角（智谋）
  哪些信息是读者能感受到但看不清的"已知的未知"？

如果是反转张力：
  反转的前提铺垫在哪里？（没有铺垫的反转是突兀，不是张力）
  反转揭露后，之前的哪些细节会被读者重新解读？

如果是反转张力且本节为高潮/强冲突节点（涉及反派或对立面）：
  反派在高潮时不能是被动的（站着不动、震惊失语、只会瞪眼）。
  反派的反应必须出人意料但符合他的人性逻辑。
  最可怕的不是高潮时露出獠牙，而是高潮时做了一个「完全正常」的事，让主角后背发凉。
  tension_execution 中须写明：反派的具体反应动作、为何既合逻辑又出人意料。

如果是推波助澜张力：
  知情者的动机是什么？（为什么选择利用而不阻止）
  他在利用谁的什么行为？（算计要具体）
  他的行动方式是什么？（必须有在当下合理的表面解释，不能是当场就能被看穿的异常）
  他的马脚在哪里？（事后才能被发现的细节，不是当场暴露的破绽）

如果是困境张力：
  主角知道什么真相？
  什么原因让他无法改变局势？（不是能力不够，是什么条件制约）
  他尝试了什么？为什么失败了？

如果是代价张力：
  这次推进的代价是什么？（必须具体，不能抽象）
  代价是不可逆的吗？为什么回不了头？
  代价和收益的比例是否让读者感到"值得但心疼"？

如果是悬念张力：
  本节揭露的表层真相是什么？（让读者暂时松了口气）
  更深的真相是什么？（在后续节点才揭露）
  通过什么细节让读者感受到"还有什么没被说出来"？
```

## 四、`prompts/creation/expand2.py` 修改

### 在 EXPAND2_USER_TEMPLATE 里新增"张力落地设计"段落

位置：在场景的 core_conflict 说明之后新增。

```
【张力落地设计】

本节的张力分析结果：{tension_analysis}（来自 expand1）

将张力分析转化为具体场景设计：

信息差的场景表现：
  不同人物在同一场景里，因信息量不同而做出不同反应
  要让读者在阅读时感受到"他们看到的是同一件事，但理解完全不同"
  设计具体的时刻：什么信息在这个场景里被谁知道、被谁错过

推波助澜的场景表现：
  知情者的"不作为"必须有具体的行为载体，不是纯粹的沉默
  好的表现方式：
    轻描淡写地转移话题
    用一个模棱两可的回答暗示而不直说
    在关键时刻假装没看见
    用一个普通的日常动作掩盖算计
  禁止：只写"他没有说话"，没有行为承载的不作为没有张力

  ★ 推波助澜者的行为必须有当下合理的表面解释：
    知情者是懂得伪装的，他的行为在当场看起来完全正常
    马脚是不经意犯下的错，是事后才能被发现的异常
    不是当场就能被看穿的"意味深长"
    设计推波助澜者的行为时，先问：
      这个行为在不知情的人眼里是什么？（必须有合理解释）
      这个行为在知情者（主角）事后回想时意味着什么？（才露出破绽）
    示例：
      ❌ 知情者"意味深长地笑了一下"（当场就被读者看穿）
      ✅ 知情者恰好在那个关键时刻低头找东西，
         话题自然地被岔开，没有人觉得刻意

反转的场景铺垫：
  反转揭露前，场景里必须有伏笔
  好的伏笔：读者事后回看会发现早有暗示，但当时没注意
  坏的伏笔：太明显让读者提前猜到，或完全没有导致反转突兀

  ★ 反转必须同时推翻读者已经建立的"完整解释"：
    有效反转的条件：
      读者在反转之前已经建立了一个错误但合理的完整解释
      反转揭露时，不只是"新信息出现了"
      而是"之前所有合理的判断同时崩塌了"
    检验标准：
      在设计反转节点之前，先问：
      "读者此时对局面的完整解释是什么？"
      如果读者没有建立任何解释，这个反转就没有冲击力
    示例对比：
      ❌ 无效反转：读者不知道宝藏是真是假，突然说是假的
         → 读者没有建立"宝藏是真的"的完整认知，反转无力
      ✅ 有效反转：读者跟着主角相信了宝藏存在的所有证据，
         建立了完整的"宝藏在山里"的认知，
         最后揭露整个藏宝图是恶鬼的诱饵
         → 之前所有"合理"的判断同时崩塌

困境的场景表现：
  主角的尝试必须具体可见
  他失败的原因要让读者感到"确实没办法"，不是主角太弱

代价的场景表现：
  代价必须在场景结束时具体呈现，不能只是叙述
  读者要亲眼"看到"损失，不是被告知有损失

悬念的场景表现：
  表层谜题解决时，同时植入一个让读者产生新问题的细节
  这个细节不能太明显，要让读者有"等等，这个细节是什么意思"的感觉
```

## 五、`prompts/creation/write.py` 修改

### 在 WRITE_SYSTEM 里新增"张力写法"板块

位置：在【人物表现禁忌】之后新增独立板块。

```python
WRITE_SYSTEM 新增内容：

"""
【六种张力的写法规范】

信息差张力的写法：
  不同人物对同一件事的反应要写出差异
  反应差异来自信息量的不同，不来自性格的不同
  禁止用旁白直接说明"他知道而另一个人不知道"
  让读者自己从反应差异中感受到信息不对称

推波助澜张力的写法：
  知情者的"不阻拦"必须有具体行为承载：
    他在做什么？（一个在当下完全合理的普通行为）
    这个行为的表面解释是什么？（其他人看到这个行为的理解）
    这个行为事后回看意味着什么？（主角或读者回想时才发现的破绽）
  禁止：只写"他没有说话"或"他选择了沉默"
  禁止：用"意味深长的微笑"或"深邃的眼神"暗示知情——
        这是当场就能被看穿的表演，真正的老手不会这样
  正确示例：
    ❌ "师爷意味深长地看了算命先生一眼"
    ✅ "师爷低头翻了翻背包，说今晚的手电筒带够了吗，
       话题就这么岔了过去，没有人觉得刻意"

主角推理的写法：
  主角察觉异常必须从"身份与行为的矛盾"出发，不是直觉
  正文里必须具体写出主角观察到了什么异常：
    他注意到什么具体细节？（行为/表情/时机/措辞）
    这个细节和这个人的身份预期有什么落差？
    这个落差让主角产生了什么具体的判断？
  读者必须能跟着主角的观察复现这个推理过程
  禁止：
    ❌ "主角感到有些不对劲"（直觉，没有过程）
    ❌ "主角敏锐地察觉到了异常"（结论，没有依据）
    ✅ "王老板说刚买的房，但进门时没有四处打量，
       径直走到西侧墙边站定，像一个来过很多次的人"

反转张力的写法：
  反转揭露之前，正文里必须有伏笔
  伏笔的标准：读者事后回看会发现"原来早有暗示"
  伏笔的位置：往往在读者注意力集中在别处的时候植入
  反转揭露时，不要急着解释，先让冲击感停留一秒
  反转必须同时推翻读者已建立的完整解释：
    不只是"新信息出现了"
    而是"之前所有合理的判断同时崩塌了"

高潮/强反转场景中反派表现：
  禁止用「静止」「沉默」「愣住」单独表现反派的震惊
  反派必须有一个具体的、出人意料的反应动作（可配合平常话或日常动作）
  让读者感到寒意，而不是只会「震惊」

困境张力的写法：
  主角的尝试必须具体写出来，不能略过
  失败的原因要通过场景呈现，不通过叙述说明
  无力感来自"已经尽力了但没用"，不来自"放弃了"

代价张力的写法：
  代价必须是具体可见的，不是抽象的总结
  差的写法："他付出了很大的代价"
  好的写法：
    "他回头，原来跟在身后的七个人，
     现在只剩下两个，其中一个还在流血"
  代价越具体，读者越能感受到危机是真实的

悬念张力的写法：
  表层谜题解决后，用一个细节植入新的疑问
  这个细节不直接说明什么，只是让读者觉得"有什么不对劲"
  禁止写："主角感觉还有什么没说清楚"
          → 这是在告诉读者要感到不安
          → 应该用一个具体的细节让读者自己产生不安感
"""
```

## 七、核心原则（供 Cursor 理解改动意图）

```
六种张力形式：
  信息差张力：同一事件，不同人物不同信息，不同选择
  反转张力：已建立的预期被打破；须能推翻读者已建立的完整错误解释（配合 expand2/write）
  推波助澜张力：知情者主动利用他人的无知或错误；行为在当下有合理表面解释，马脚事后才被发现
  困境张力：主角知道真相但无法改变局势
  代价张力：每次推进都有具体的、不可逆的真实代价
  悬念张力：读者感受到还有更深的真相未被揭露

主角推理逻辑：
  察觉依据必须是"身份与行为的矛盾"，不是直觉
  已知身份预期 + 实际行为 = 矛盾 → 推导出隐情
  正文里必须具体呈现观察细节和推理过程（禁止"感觉不对劲"式直觉）

四个节点的分工：
  path_gen：规划整批节点的张力分布和节奏；反转老套性检验（双层揭露）
  expand1：张力分析 + 推理逻辑分析（身份与行为矛盾）+ 专项张力执行要点
  expand2：张力落地；推波助澜须有隐蔽性与表面解释；反转须推翻完整解释
  write：落实张力写法；主角推理可复现；禁止意味深长式表演暗示知情
```
