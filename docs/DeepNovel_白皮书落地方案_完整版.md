# DeepNovel 白皮书落地方案（开发期无遗产数据最终版）

> **⚠️ 执行前提声明**
> 截止本方案编撰时，项目处于开发测试阶段，**完全无需兼容旧正式数据**。
> 这意味着在落地《大乘圆满版白皮书》时：**允许全库重命名、允许破坏性删除废弃字段、无需写容错迁移代码**。这是一次彻底的“破后而立”。

## 1. 核心架构映射定律

| 层级 | 核心设计意图 | 工程结构载体（落桩点） |
|---|---|---|
| **第一层 灵魂层** | 【Mental Core 五维面板】决定承受力；【先天底色】拒绝被同化；【情感透支】爆发定律 | 主角卡/草稿卡 JSON（弃用单纯趋态）；`schemas/entity.py` 字段增改；`bible_update` 精神增量抽取。 |
| **第二层 动力层** | 世界并非善恶阵营二分，而是由【有限资源分配】导致的【灰度势力与制衡】 | 废弃单薄的“蔑视名单`untouchable_characters`”，代之以 `dynamic_gray_factions`；大世界设定强关联地缘与生态垄断。 |
| **第三层 演化层** | 所有冲突皆为资源的夺取与消耗；所有动作均依赖主角的精神侧触发并引发未来之果 | `path_gen` 新增 `karmic_resources`(四维弹药) + `mental_lever`(精神扣机)；`event_chain` 强化 `connection_to_previous` (前果后因)。 |
| **第四层 节奏层** | 动态适应庞杂体系，告别微操流水账 | `story_arc_plan` 章节数下限拉起，微小危机在前两个里程碑内极速收敛，大案实行波段切片。 |
| **第五层 奇点层** | 凡是用户指定的剧情锚定，对系统即为神圣真理不可更改 | `idea_forge` 数据结构锁定；后续生成的验证节点对其进行查漏补缺式校验。 |
| **第六层 呈现层** | 影视切片呈现；摈弃上帝视角反派的智障叫嚣；成年人的战损与松弛感交互 | `write.py` 的文学铁律重注入（视听维度）；`consistency.py` 中对“Show，Don't Tell”施加否决权。 |

## 2. 三大不可违背全局轴心

1. **正交扩展，绝不替代（破局之法）**
   - **四维资源（信息差 / 人际杠杆 / 时间差 / 地理优势）**是子弹库。
   - **既有策略（提前察觉 / 局中挣扎等）**是射击方式。
   - 二者必须在推演节点中并行存在，禁止用前者抹杀后者。
2. **反脸谱化的精神逻辑（人物之本）**
   - “抛弃幻想”是高心智，但不等于“滥杀无辜”。高成熟度体现为极端的冷酷利益交换，但也意味着极高昂的逆鳞底线。大悲与缜密杀伐可以完美兼容，不需要强行降智来表现情绪。
3. **篇幅动态扩展（节奏之门）**
   - 全局架构不锁死总数字，长篇（50-150章/卷）只需做好事件切片；如果走短篇模式流派，由项目全局配置（Config）覆盖，避免系统被大而全的长篇定式拖死。

## 3. 破坏性重构开发计划（按序推进）

由于没有线上包袱，我们可以采取最彻底的“流血大清洗”。

### Phase A: 清理与确权（破局战）
*   **动作**：全仓库发起全局 `grep`。
*   **目标**：
    *   将 `untouchable_characters` 全库无情替换为 `dynamic_gray_factions`（涵盖 `state.py`, `story_arc_plan_node.py` 及其提示词等）。
    *   完全剔除出所有的 `behavioral_tendencies` 依赖，准备向 `MentalCore` 进化。

### Phase B: 灵魂架构搭建（基石战，对应第一层）
*   **动作**：更新 `schemas/entity.py`。
*   **目标**：追加增量类 `MentalCore`，给 `CharacterCard` 实装 `innate_traits`, `mental_core`, `maturity_note`, `emotional_drain`。打通 `world_build.py` 里的初始化 Prompt。

### Phase C: 动力与演化注入（腹地战，对应第二/三层）
*   **动作**：更新 `path_gen.py` 与 `event_chain_gen_node.py`。
*   **目标**：在 JSON 返回值中强势填入 `karmic_resources` 和 `mental_lever`。将所有事件的连接词语从单纯的“接上一章”改造为带有遗产继承关系的“【因果闭环继承】：上一个事件带来的哪项资源/负累引爆了当前事态？”。

### Phase D: 全局锚点与文学终裁（合围战，对应第五/六层）
*   **动作**：更新 `idea_forge_node.py`、`bible_update.py`、`write.py` 和 `consistency.py`。
*   **目标**：给用户的指定锚点贴上 `immutable` 警告；给大模型写章加装“感官漏斗”与“不可直接陈述内心悔改”的枷锁。
