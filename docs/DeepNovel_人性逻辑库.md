# DeepNovel 人性逻辑库 — Cursor 修改建议

> 人性逻辑是一个人面对处境时的底层思维方式，不是手段，不是性格标签。
> 核心标准：这是一套可以被模型直接执行的思维程序，不是描述词。
> 人性逻辑从人物的背景、经历、性格特质中推导而来，不是外挂的标签。

---

## 一、数据模型修改

### 1.1 新增 `HumanLogic` 模型（`schemas/entity.py`）

```python
class HumanLogic(BaseModel):
    logic_name: str              # 逻辑名称
    core_essence: str            # 核心本质（一句话说清楚这种逻辑的本质）
    trigger_conditions: list[str] # 触发条件（什么处境下启动）
    execution_steps: list[str]   # 执行程序（可被模型直接执行的步骤）
    termination: str             # 终止条件
    failure_risks: list[str]     # 失败风险
    origin: str                  # 这种逻辑通常由什么经历/处境塑造
```

### 1.2 `CharacterCard` 新增字段（`schemas/entity.py`）

```python
class CharacterCard(BaseModel):
    # 原有字段不变...

    # 新增
    background_summary: str = ""
    # 出身、家世、进入当前处境前的关键经历
    # 决定了这个人有哪些可用资源和心理底色

    key_life_events: list[str] = Field(default_factory=list)
    # 塑造了这个人核心行为模式的重大经历
    # 决定了这个人为什么形成某种人性逻辑而不是另一种

    dominant_logics: list[str] = Field(default_factory=list)
    # 这个人主导使用的人性逻辑名称列表
    # 从 background_summary + key_life_events + traits 推导而来
    # 示例：["设局逻辑", "忍辱逻辑"]

    logic_switch_conditions: list[dict] = Field(default_factory=list)
    # 极端处境下会切换到哪种逻辑
    # 格式：[{"condition": "走投无路时", "switch_to": "绝境逻辑"}]
```

在 `EXPAND1_USER_TEMPLATE` 里，在性格反应分析之后增加：

```
【人性逻辑分析】

本节涉及人物的主导逻辑：
{character_logics_formatted}

分析以下三个问题：

1. 本节场景触发了哪个人物的哪种人性逻辑？
   该逻辑目前执行到第几步？

2. 不同人物的逻辑之间有什么碰撞或利用空间？
   示例：设局逻辑的人是否在利用舔狗逻辑的人的盲点？
         忍辱逻辑的人是否在等待对方的绝境逻辑暴露破绽？

3. 对方对当前局面的错误认知是什么？
   这个错误认知如何被主角（或对手）利用？

输出格式：
  logic_analysis: [
    {
      "character": "人物名",
      "active_logic": "人性逻辑名称",
      "current_step": "正在执行第几步，具体描述",
      "opponent_blind_spot": "对方的错误认知是什么",
      "exploitation_point": "这个错误认知如何被利用"
    }
  ]
```

### 3.2 人性逻辑的注入方式

在 `expand1_node.py` 里，加载涉及人物的人物卡时，同时从 `HUMAN_LOGIC_LIB` 里加载对应逻辑的执行程序：

```python
from knowledge.human_logic_lib import HUMAN_LOGIC_LIB

def format_character_logics(character_cards: list) -> str:
    result = []
    for card in character_cards:
        for logic_name in card.get("dominant_logics", []):
            logic = HUMAN_LOGIC_LIB.get(logic_name, {})
            if logic:
                result.append(
                    f"{card['standard_name']} — {logic_name}\n"
                    f"  核心：{logic['core_essence']}\n"
                    f"  执行程序：\n" +
                    "\n".join(f"    {step}" for step in logic['execution_steps'])
                )
    return "\n\n".join(result) if result else "无记录"
```

## 四、人物卡建立时的逻辑推导

### 4.1 在世界设定和主角人物卡确认之后，模型根据以下信息推导主导逻辑

Prompt 片段（在人物卡生成时使用）：

```
根据以下人物信息，推导这个人物最可能使用的1-2种人性逻辑：

背景经历：{background_summary}
重大事件：{key_life_events}
性格特质：{traits}
当前处境：{current_status}

可选的人性逻辑：
{logic_names_and_essences}

推导要求：
  逻辑必须从背景和经历中自然生长出来，不能随机分配
  同一个人在不同处境下可能切换逻辑（记录在 logic_switch_conditions 里）
  
输出：
  dominant_logics: ["逻辑名称1", "逻辑名称2"]
  logic_origins: ["逻辑1为什么符合这个人的经历", "逻辑2为什么符合"]
  logic_switch_conditions: [{"condition": "极端处境描述", "switch_to": "切换的逻辑名称"}]
```
