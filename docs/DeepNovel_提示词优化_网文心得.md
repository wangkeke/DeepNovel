# DeepNovel 提示词优化文档 — 基于网文写作心得

> 基于知乎网文写手的创作经验，对四个核心节点的 Prompt 进行全面优化。
> 核心理念：
>   小说可以不现实，但必须自洽
>   逻辑闭环不是首尾呼应，而是每个情节点都在对应的位置上
>   伏笔是"回头看"的惊喜，悬念是"向前看"的动力，谜语人是阅读的毒药
>
> 改动范围：四个 Prompt 文件，不涉及执行逻辑。

---

## 一、核心写作原则提炼

在所有节点的 Prompt 里统一注入以下基础认知：

```
【写作基础原则】

逻辑自洽原则：
  小说可以不现实，但必须自洽
  现实文/历史文：符合现实世界规则，人物行为符合人性
  玄幻/修仙/穿越文：在自己设定的世界里，规则必须自己遵守
  无论哪种类型，以下三种情况必然被读者骂"不合理"：
    人物行为逻辑崩坏：前面冷静理智，后面突然降智送人头
    前后设定矛盾：自己打破自己的世界观
    为了爽而强行爽：毫无铺垫强行开挂

逻辑闭环原则：
  每个章节必须有自己的起承转合（小闭环）
  小闭环是大闭环的台阶，不是孤立的单元
  小闭环的标准结构：预期 → 意外 → 收束
    预期：给读者一个"这件事要怎样发展"的期待
    意外：打破这个预期（意外不是突兀，是合理的出乎意料）
    收束：真相大白或人物获得成长，且为下一个小闭环留下线头

人物成长原则：
  人物成长不是最后一章才完成的，是每个小章节积累的结果
  人物成长 = 所有选择的总和
  每次选择都必须有具体的困境作为前提
  选择本身就是逻辑的闭环

谜语人禁忌：
  在生死关头，任何故弄玄虚都是致命的
  判断标准：如果一个角色说的话，除了作者没人能懂，就是谜语人
  人物说话必须有明确的战术目的
  对读者诚实，对角色保密
  不能为了制造神秘感而牺牲逻辑清晰度
```

## 二、`prompts/creation/path_gen.py` 修改

### 2.1 新增"章节闭环规划"段落

位置：在张力规划段落**之后**，节点列表输出**之前**。

```
## 章节闭环规划（每个节点都必须完成）

每个节点对应一个独立的完整场景，必须符合小闭环结构：

【小闭环三要素（必须全部具备）】

1. 预期（给读者一个期待）：
   这个节点开始时，读者基于之前的信息，会预期发生什么？
   这个预期要真实存在，不能是凭空制造的悬念

2. 意外（打破预期）：
   意外不等于突兀
   好的意外：读者事后回看，会发现"早就有信号，只是没注意"
   坏的意外：完全没有铺垫，读者感到被欺骗而不是被惊喜

3. 收束（结果 + 线头）：
   结果：这个节点最终怎样了，必须有明确的结果，不能悬在空中
   线头：结果里必须包含一个推动下一个节点的动力
   好的收束：节点结束时，下一个问题已经悄悄浮现

【闭环检验问题】
规划每个节点时，先回答：
  读者读完这个节点，会有"然后呢"的期待吗？
  这个节点的结果，为什么会导致下一个节点的开始？
  如果把这个节点删掉，故事会不连贯吗？
  如果删掉后故事仍然连贯，这个节点是多余的

【人物选择驱动原则】
节点的转折必须由人物选择驱动，不能由作者强行推动：
  ❌ 强行转折：主角莫名其妙去了某个地方，遇到了关键人物
  ✅ 选择转折：主角基于当前处境做出一个选择，这个选择导致了新的局面
  每个转折前，都要能回答：这个人物为什么会做这个选择？

## 节奏控制

每批节点必须包含弛张变化：
  不能全是高压节点（读者会疲惫）
  不能全是轻松节点（读者会无聊）
  建议比例：
    建立期：3张1弛
    升级期：2张1弛
    高潮前：3张0弛（连续紧张，为高潮蓄力）
    落定期：1张2弛

弛节点的用途：
  不是无意义的水字数
  是让读者喘口气，同时为下一波张力埋下伏笔
  世界线事件往往承担弛节点的功能
```

## 三、`prompts/creation/expand1.py` 修改

### 3.1 新增"逻辑自洽检验"步骤

位置：在推理逻辑分析之后，信息差分析之前。

```
【逻辑自洽检验（在场景设计前完成）】

对本节涉及的每个关键行为，回答以下问题：

人物行为的逻辑一致性检验：
  这个人物之前建立的性格特质，支持他在本节做出这个行为吗？
  如果之前是冷静理智的人，本节突然冲动，必须有明确的触发原因
  行为的改变必须来自积累的压力或特定的触发事件，不能凭空改变
  
  检验标准（"行为-性格一致性矩阵"）：
    行为 × 性格特质 = 是否自洽
    例：忍辱逻辑的人 × 突然正面反击 = 不自洽（除非触发了底线）
    例：设局逻辑的人 × 正面对抗 = 不自洽（除非正面对抗是局的一部分）

设定内部矛盾检验：
  本节涉及的世界规则，是否与之前建立的设定一致？
  如果有规则变化，必须有合理的解释
  
强行爽点检验：
  本节有没有"毫无铺垫强行开挂"的情节？
  如果主角突然有了新能力或新资源，这个能力/资源是否有前置铺垫？
  每一次爽点都必须有对应的代价或积累

【人物选择驱动场景设计】

本节的核心场景必须由人物选择驱动：
  这个人物面临什么具体的困境？
  在这个困境里，他有哪些选择？
  他为什么选择了这个而不是那个？
  这个选择的代价是什么？

本节场景结束时，必须留一个"线头"：
  不是强行制造悬念
  而是这个选择自然导致的下一个问题
  读者应该感受到"这件事还没完"，而不是"作者在憋大招"
```

## 四、`prompts/creation/expand2.py` 修改

### 4.1 新增"伏笔场景设计"段落

位置：在张力落地设计之后。

```
【伏笔场景设计规范】

伏笔必须自然生长，不能硬埋：

好的伏笔设计（草蛇灰线）：
  伏笔藏在"无关紧要"的场景里，当时看起来只是环境/情绪/细节
  伏笔要和情节在一起成长，不是后续需要用到时再回头添加
  读者事后回看会发现"早就告诉过了"——这是公平交易
  伏笔揭晓时的震撼：意料之外，情理之中

坏的伏笔设计（机械降神）：
  ❌ 关键人物突然出现救场，之前毫无铺垫
  ❌ 主角突然掌握关键信息，来源不明
  ❌ 道具突然有了新功能，之前没有暗示
  ❌ 结尾前才急忙在前面添加的伏笔

伏笔的三个层次：
  第一层（细节伏笔）：
    藏在环境描写或无关紧要的动作里
    功能：建立世界的真实感，同时为后续埋下基础
    示例：宇文成都的兵器"入石三分"——不只是渲染，是内心挣扎的具象化

  第二层（人物伏笔）：
    藏在人物反常的行为或语气里
    功能：暗示人物有隐情或将要做出关键选择
    示例：师爷的"沉而不发"——合理但反常，事后才发现是在利用算命先生

  第三层（结构伏笔）：
    一个事件或状态，在后续将以完全不同的方式重新出现
    功能：首尾呼应，让整个故事形成大闭环
    示例：甄嬛从"被纯元支配"到"利用纯元"——伏笔本身成为角色的武器

本节场景需要植入或回收的伏笔类型（来自 expand1 的分析）：
  {foreshadow_plant_type}（需要植入的伏笔）
  {foreshadow_collect_type}（需要回收的伏笔）

植入伏笔时的场景设计原则：
  伏笔要"自然融入"当前场景的主要情绪和动作
  不能让读者感受到"作者在故意埋伏笔"
  伏笔对象（道具/动作/话语）必须在场景里有其自身存在的理由

【悬念场景设计规范】

悬念的目的是"期待感"，而不是"困惑感"：

层层递进的悬念设计：
  不要一次性抛出所有谜题
  给出一个小线索，解决一个小疑问，同时引出更大的疑问
  悬念的解答过程像剥洋葱：每剥一层，发现里面还有一层

双重倒计时模型（高压场景适用）：
  生理倒计时：客观存在的时间压力（期限/危险临近）
  心理倒计时：人物内心的决策压力（选择窗口正在关闭）
  两个倒计时同时运行，产生"走钢丝"的紧迫感

悬念场景的禁忌（谜语人陷阱）：
  ❌ 人物在关键时刻说出只有作者能懂的话
  ❌ 明明可以说清楚却故意模糊，导致剧情逻辑不通
  ❌ 为了保留悬念而让人物做出不合理的选择（比如明明可以逃却不逃）
  ❌ 主角在生死关头还在"高深莫测地笑"

正确的悬念制造方式（阳谋）：
  人物的每一句话都必须有明确的战术目的
  让读者知道人物在做什么，但不知道结果
  "走钢丝"的紧迫感来自"目标明确但成功率未知"，不是来自"我也不知道在干什么"
```

## 五、`prompts/creation/write.py` 修改

### 5.1 在 WRITE_SYSTEM 里新增"小闭环写法"和"谜语人禁忌"板块

位置：在张力写法板块之后。

```python
WRITE_SYSTEM 新增内容：

"""
【章节小闭环写法】

每章必须有完整的"预期-意外-收束"结构：

开头建立预期：
  开头不是单纯的场景铺垫，而是在建立读者的预期
  好的开头会让读者心里隐隐产生一个问题："这会怎样发展？"
  这个问题不需要明说，用细节和节奏自然传达

中间制造意外：
  意外必须是"合理的出乎意料"，不是"莫名其妙"
  意外发生前，正文里必须已经埋下了信号
  信号的特点：当时看起来无关紧要，事后回看才发现关键
  意外发生时，不要急着解释，先让冲击感停留：
    一个停顿、一个无声的反应，比立刻的解释更有力量

结尾完成收束：
  每章结尾必须有明确的结果，不能悬在空中
  结果里必须包含一个"线头"：推动读者翻开下一章的动力
  线头不是强行制造悬念，而是结果自然产生的下一个问题
  
  好的结尾：给了一个答案，但这个答案引出了更大的问题
  差的结尾：
    ❌ 纯粹的悬念（什么都没解决，只是在憋大招）
    ❌ 纯粹的总结（把刚刚发生的事情重新概括一遍）
    ❌ 人物的自我反思段落（主角躺在床上想了很多）

【伏笔写法】

草蛇灰线，不能让读者感受到"作者在埋伏笔"：
  伏笔必须有其在当前场景里自身存在的理由
  不能只为了伏笔而写伏笔

好的伏笔写法：
  把伏笔藏在当前场景的情绪和动作里：
    不是单独的一句"描写"，而是融入人物的行为或心理
    示例：
      ❌ "桌上有一把匕首，在阳光下闪闪发光。"（孤立的伏笔描写）
      ✅ "她收拾东西时，手指碰到了那把从不离身的匕首，
          停了一秒，然后继续整理，没有带走它。"（融入行为的伏笔）

伏笔回收时的节奏：
  揭晓时先让读者产生"等等……"的感觉
  然后才是"原来如此！"的恍然大悟
  这两个反应的时间差，就是伏笔的震撼所在
  不要在揭晓的同时急着解释，让读者自己想一秒

【谜语人禁忌】

以下写法是阅读的毒药，必须避免：

谜语人的典型表现：
  ❌ 人物在关键时刻说出只有作者能懂的话
     "有些事，你现在还不明白……"
     "时候未到，一切自有分晓。"
  ❌ 人物明明可以说清楚，却故意模糊
  ❌ 在生死关头，主角还在"意味深长地笑"
  ❌ 主角拥有关键信息却不采取行动，只为制造紧张感

谜语人的危害：
  破坏作者与读者的信任契约
  让读者从"期待"变成"困惑"，最终变成"愤怒"
  一旦被读者认定为谜语人，后续的所有悬念都会失去可信度

正确做法——对读者诚实，对角色保密：
  读者可以看到所有信息，但人物之间的信息是不对称的
  悬念来自"读者知道但人物不知道"（焦虑感）
  或"读者和人物一起不知道"（期待感）
  不是来自"作者故意不告诉读者"

人物在关键时刻说话的原则：
  每一句话都必须有明确的战术目的
  阳谋比谜语更有震撼力：
    ❌ "你知道你错在哪里吗？" （谜语人）
    ✅ "你知道这份账本放在哪里吗？我知道。" （阳谋，信息差反制）

【设定自洽原则】

如果之前建立了世界规则，必须自己遵守：
  不能为了一个爽点打破之前的规则
  如果规则发生变化，必须在正文里有合理的解释
  
强行爽点的识别：
  主角毫无铺垫地展示出之前从未暗示过的能力
  → 读者的感受是"被糊弄"，不是"被惊喜"

正确的爽点写法：
  爽点必须有积累支撑：之前的困难积累了多少，爽点就有多大
  爽点必须有代价平衡：完全没有代价的胜利是空洞的
  爽点必须有前置信号：读者在爽点揭晓之前，已经有了"会不会……"的猜测
"""
```

## 七、path_gen 新增全局约束

在 PATH_GEN_SYSTEM（非 USER_TEMPLATE）里加入：

```
【全局写作原则（适用于所有节点规划）】

逻辑自洽高于一切：
  在这部小说的设定里，规则一旦建立就必须遵守
  任何"为了爽而强行开挂"的节点设计都必须否决
  主角每一次破局，必须有对应的前置积累或代价

小闭环链接大闭环：
  每个节点是大闭环的一块台阶，不是孤立的单元
  节点与节点之间必须有因果链：前一个节点的结果，是后一个节点发生的原因
  不是"然后……然后……然后……"的流水账
  而是"因为……所以……于是……"的因果推进

禁止以下设计：
  ❌ 节点之间没有因果关联，只是事件的堆砌
  ❌ 人物行为前后矛盾（除非有明确的触发原因）
  ❌ 高位者无缘无故针对主角（违反做局动机合理性）
  ❌ 主角凭运气或巧合破局（破坏逻辑）
  ❌ 节点没有明确的结果（悬在空中）
```

## 九、核心原则速查表（供 Cursor 理解改动意图）

```
逻辑自洽：
  小说可以不现实，但必须在自己的设定内自洽
  人物行为必须与性格特质一致，改变需要触发原因

逻辑闭环：
  小闭环：每章"预期→意外→收束"，收束里留线头
  大闭环：所有小闭环积累的结果，人物成长的最终体现
  伏笔：和情节一起成长，不是硬埋；揭晓时"意料之外，情理之中"
  悬念：层层递进，剥洋葱；目的是"期待感"不是"困惑感"

谜语人：
  对读者诚实，对角色保密
  人物说话必须有明确战术目的
  阳谋比谜语更有震撼力

人物成长：
  成长 = 所有选择的总和
  每个节点都是积累，不是孤立事件
  只有人物走到这一步，对应的伏笔才能揭开
```
