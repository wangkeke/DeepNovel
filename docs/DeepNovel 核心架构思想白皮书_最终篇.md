# 📖 DeepNovel 核心架构思想白皮书（大乘圆满版）

> **【最高总纲：有机生命体与独立智能体沙盒】**
>
> 小说绝不是事件的机械堆砌，而是"角色"在特定世界观下，通过"双向因果网络"自然碰撞、生长的有机生命体。
>
> 1. **关于"角色"的绝对定义**：每个角色（无论主角、反派还是配角）都是一个【完全独立的智能体】。他们只对自己的立场、智商和利益负责，有着自己独立的生活轨迹，绝对不是为了服务主角而存在的工具人。
> 2. **并非事件推动人，而是【人推动事件】**：这里的"人"，不仅指单个角色，更涵盖【任意群像与宏观势力】。例如：角色A失手杀了侯府千金（个体驱动）；皇后为了立威要求群妃参加百花宴（上位者驱动）；魔教向黄风谷发起全面总攻（势力/群像驱动）。这个世界的齿轮，是由无数个个体和群体的意志交织咬合而转动的。

## 第一层：灵魂层 —— 精神内核、成熟度与独立人设（The Soul）

**核心理念：角色的行为逻辑，完全取决于其"出厂设置（性格）"与"后天升级（成熟度）"的综合运算。**

角色的人格是一套极其严密的三维模型：

**1. 先天属性（出厂设置 / 终生不改的底色）**

包含角色的先天性格与生理/天赋特征。如：贪财、护短、极度虚荣、冷清、市侩、多疑；也可以是暴躁易怒、头脑简单、有几分急智（如袁绍之流）、四肢发达、憨直、目力过人（如项云峰）等。这是角色评判世界、做出本能反应的基石，至死不会根本改变。

**2. 精神层面（Mental Core / 综合属性面板）**

它是支撑角色做出高阶决策的内在硬件。具体量化为五大核心维度：【心智（智商与社会阅历）、情商、思维缜密性、情绪控制力、隐忍度】。

⚠️ 精神资源定律：精神层面不仅是属性，更是【极其昂贵的内耗型资源】！角色为了大局强行隐忍、或目睹惨剧，会剧烈消耗其"情绪控制力（精神阈值）"。当精神资源透支归零时，必然触发不计代价的底线爆发。

**3. 成熟度（Maturity / 精神层面的量化标尺）**

成熟度是用来【衡量】上述"精神层面五大维度"发展水平的刻度。角色的精神成长，可能是五个维度的全面升华，也可能是针对某几个点（如社会阅历、隐忍度）的单点突破。

成长的来源有两条路径：其一是【现实经历的残酷毒打】，其二是【社会阅历的不断积累】——作为旁观者看得多了、作为亲历者经历得多了，自然从中汲取了智慧。成长不一定源于被击败，也可以是沉默中的沉淀。

⚠️ 认知的辨证（破除表象）：注意！"对外部抱有不切实际的幻想（如幻想敌人仁慈、幻想被爱）"仅仅是心智不成熟的【外在症状表现】，而非成熟度本身的定义。当角色的心智、情商、阅历真正成熟时，他们自然会认清丛林法则的残酷底色，丢弃幻想，减少内耗，从而展现出极其冷酷缜密的算计与杀伐。

情绪的辩证法：成熟度高绝不等于"面瘫/失去情感"。成熟的角色在逆鳞被触（如亲友惨死）时，依然会极致悲恸、大哭发泄；但高成熟度让他们在发泄【同时或之后】，能瞬间转化为极其缜密、不计代价的正面对决与杀伐。

## 第二层：动力层 —— 资源竞争、人性灰度与多边博弈（The Physics）

**核心理念：善恶不是固定标签，而是资源竞争下利益关系的外在投影；世界的底色永远是灰色的。**

**1. 世界的底层逻辑是资源竞争**

世界中的资源（权力、金钱、领土、修为、情感）永远是有限的。当足够多的人与势力共存时，资源的稀缺性必然驱动所有个体走向"利益最大化"的底层算法——这是生存的本质，无关道德高低。正因如此，冲突不是人为制造的戏剧，而是有限资源下的必然结果。

**2. 善恶是动态的利益投影**

正因如此，"正派"与"反派"绝非固定身份。同一个人或势力，在利益契合时可以成为坚定盟友，在利益冲突时可以瞬间反目成仇。慕容复可以联合丐帮，明教可以与武当共御外敌——阵营的流动，才是人性灰度的真实来源。世界是由正派（武当、峨眉、少林寺、乔峰式人物）与反派（明教/魔教、西域喇嘛、慕容复式人物）共同构成的，势力有正邪，角色亦有正邪，绝对禁止非黑即白的世界观。

**3. 多面性的根源**

角色表现出的"多面性"，本质上是同一套利益驱动逻辑在不同情境下的不同输出。他不是"变了"，他只是在每一刻都忠实地执行着自己利益最大化的内在算法。今天的死敌，可以因为共同的威胁而成为明天的盟友；今天的盟友，可以因为利益分配不均而成为明天的刀下鬼。这种流动性，为主角提供了"祸水东引、借力打力"的无限操作空间。

**4. 针对度的非线性真相**

针对度绝不等于绝对理性的利益算计（ROI）。ROI 只是高成熟度、马基雅维利式性格的专属算法。针对度来源于性格：傲慢者会因为主角"挡了路"而产生针对；虚荣者会因"容貌嫉妒"产生针对；护短者会因为"亲属受损"而倾巢出动。针对度是形形色色的角色性格，在遇到主角时自然擦出的火花。

## 第三层：演化层 —— 广义因果网络与四维状态机（The Karmic Loop）

**核心理念：四维资源只是子弹，精神层面才是扣动扳机的手。**

**1. 四维博弈实体资源（破局的子弹）**

所有的设局与反杀，绝对不能凭空想象（拒绝机械降神）。必须严格依赖四大实体条件：【信息差】（我知道你不知道的秘密）、【人际杠杆】（利用亲疏、爱恨、利益纠葛）、【时间差】（死线与时机）、【地理优势】（密室、绝地）。

**2. 精神层面的绝对主导（拿枪的人）**

⚠️ 铁律：上述四维信息仅仅是"资源"，是死的子弹。破局的关键，必须是靠角色的【精神层面（心智、情商、思维缜密性、隐忍度等）】去驱动并利用这些资源！愚蠢的角色拿到账本只会招来杀身之祸；只有思维缜密、高隐忍度的角色，才能用账本布下完美的必杀局。资源决定上限，精神层面决定能否触及上限。

**3. 双向的广义因果循环（逻辑自洽的最高境界）**

事件A的输出（果），必须是未来事件X的输入（因）。小说是双向咬合的莫比乌斯环。

角色会根据自己的【性格与隐忍度】，将资源藏在暗处，直到未来的某个关键节点才引爆。反转的本质：主角/反派以为自己在前期得到了一个"果（胜利）"，结果在【紧接着的下一个事件中】，或者在【未来的N个事件之后】突然发现，这个"果"其实是对方早早种下的"因（致命破绽）"！因果的爆发既可以是瞬间的雷霆万钧，也可以是伏脉千里的草蛇灰线。

**4. 自然生长的麻烦守恒定律**

基本需求驱动入世：主角初入新地图/新阶段，第一件事是解决【基本需求】——熟悉新环境、解决生存与立足的刚需。修仙文中是寻找修炼场所、收集修炼材料；宫斗文中是认清各宫主子、摸清人情网络与日常起居规则。基本需求的形态因题材而异，但驱动逻辑一致。

圈层跃迁：在满足基本需求后，必然结识新的人，遭遇红白交织的好事与坏事。随着职位/段位提升，进入更高圈层，必定招惹到量级更恐怖的新麻烦。麻烦的上限，永远与主角当前的段位成正比。

**4. 世界自转与引力交汇法则**

世界先行自转：事件的起点绝对不能是“为了给主角找麻烦”。必须先在主角不在场的情况下，基于各方势力的“资源焦虑”和“性格底色”，推演出世界正在自然发生的暗流（如：上位者为了立威设局、底层为了抢粮火拼）。
主角刚需驱动：明确主角当下的核心私欲或生存刚需（如：缺钱、缺药、要找人）。
命运的引力交汇（核心技巧）：绝对禁止让主角变成看客！必须通过巧妙的“资源重叠”或“信息错位”，让【主角的刚需】与【世界的暗流】发生极其自然、却又无可回避的致命碰撞！主角不是被动接任务的 NPC，是被生存和私欲“逼”进世界风暴中心的凡人。

## 第四层：节奏层 —— 宏大篇幅与波段切片（The Pacing）

**核心理念：打破短视约束，以长篇巨著的体量容纳恢弘的时代画卷。**

**1. 宏大长线与动态篇幅**

一卷必须根据信息量与世界观宏大程度，在50～150章之间动态分配，保证足够的故事纵深。⚠️【绝对禁止任何一卷少于50章】！只有庞大的篇幅，才能支撑起错综复杂的多方博弈与缓慢发酵的悬念。

**2. 极速破冰与连锁反应**

开篇的初始微型危机，必须在第1-3个里程碑内极其高光、干净利落地彻底解决，绝不拖泥带水。破局后，必须立刻用剩余的庞大篇幅，去迎接由破局引发的【更大连锁反应、新势力介入或新环境博弈】。

**3. 宏大副本的波段切片**

面对大案/大秘境，绝对禁止用一个事件敷衍。必须将其切分为多个连贯的次级里程碑（入局探索 → 规则反转 → 结盟 → 破局）。每一个里程碑只占1~3章的物理容量，保持极高的网文推进感。

## 第五层：奇点层 —— 欲望代偿与意图锚定（The Genesis）

**核心理念：所有的文学技巧与因果推演，最终都服务于读者（成年人）的精神诉求。**

**1. 欲望投射与商业化解构**

小说题材（修仙、宫斗、悬疑）只是载体与外壳。真正的核心驱动力是读者在现实中得不到的"精神代偿"——打破阶级壁垒的爽感、被偏爱/唯一选择的安全感、高智商碾压的掌控感、手撕伪善者的情绪发泄、大女主的清醒独立、大男主的实力碾压与红颜知己。情感戏与商业爽点绝非"为了加而加"，而是作为顶级调料，顺水推舟且极其自然地融入到【主线冲突】之中，绝不喧宾夺主。

**2. 用户锚点神圣不可侵犯**

用户的原始脑洞就是造物主的私货，是宇宙大爆炸的唯一奇点。系统必须【绝对忠实】于用户设定的人物、感情线和必发桥段，只做"智能补全与扩写"，并将其无缝分发到全书的各个管线中，实现"骨架是标准的，灵魂是用户的"完美人机共创。

## 第六层：呈现层 —— 智能体平权与视听沉浸（The Presentation）

**核心理念：废除上帝视角的旁白，世界是一个由多个独立灵魂组成的沙盒。**

**1. 个体绝对平权与多机位调度**

镜头切给谁，谁就是自己世界的主角。反派作恶有反派符合自身认知的"正当性"——无论是正派的侠义执念还是反派的野心逻辑，每个人的行为在其自身的认知框架内都是自洽的。

核心配角是拥有独立情报网的活人，绝对禁止降智的马后炮。允许配角基于"过度保护"或"底线不同"与主角产生真实的摩擦与争执。

鼓励幕间切片（Cutaway Scene）：通过展现反派/对立方的真实内部反应（凝重、算计或恐慌），来侧面烘托局势的严峻，制造戏剧讽刺效果。

**2. 面具的自适应与无痕进化（Show, Don't Tell）**

性格底色终生不变，但外在面具随环境自然切换。同一个角色，在高压奴役下可以极致顺从隐忍（苟），在市井自由中又可以市侩圆滑或清冷孤傲——这不是性格矛盾，而是同一底色在不同压力下的折射。

⚠️ 铁律：角色吃亏后变得成熟，绝对禁止用内心独白解释"我吸取了教训"。成长必须无痕地体现在下一次遭遇类似情境时，更缜密的布防和更果决的行动之中。让读者自己感受到变化，而非被告知。

**3. 感官滤镜与成年人的松弛感**

情绪描写必须被解构为具体的【视界 + 听界 + 触界 + 极速的微观心理活动】，而非空洞的"她很愤怒""他很紧张"。

在生死间隙，必须允许角色有成年人特有的"松弛感"或"冷幽默神回复"，以此反衬世界的残酷，赋予小说极强的人味儿与呼吸感。紧绷到极致的叙事如果没有这种间隙，会令读者窒息而非沉浸。

让我先把这个难点说清楚：

---

## 问题的真正所在

我们之前所有的提示词，包括"每个角色是独立智能体"这条铁律，**本质上仍然是在告诉模型应该怎么想**。

但模型在实际生成时，它的注意力重心天然地会落在：

> "主角下一步会发生什么？"

然后**倒推**非主角的动机来配合这个方向。

这不是提示词写得不够好的问题，这是**单线程生成的结构性缺陷**。

你问的"如何让模型在非主角角色上想到起点"，本质上是在问：

> **如何让世界在主角不存在的情况下，先自己转起来？**

---

## 这个问题用提示词是解决不了的

这是一个**架构问题**，不是提示词问题。

任何一条提示词，无论写得多好，都是在同一个上下文窗口里生成的——主角的信息在那里，模型不可能真正"忘掉"主角去独立模拟其他角色的世界。

---

## 真正的解决方案：世界自转节点（World Tick）

在进入任何一个故事单元之前，系统需要运行一个**独立的、不包含主角视角的生成步骤**：

```
PROMPT · 世界自转节点（World Tick）

【你的身份】
你是这个世界的无感情观察者。
你的任务不是讲主角的故事，
而是模拟：如果主角不存在，这个世界此刻正在发生什么。

【输入】
你只会收到以下信息：
- 当前时间节点的世界状态
- 各方势力的资源处境
- 每个重要角色的：先天性格 + 精神层面状态 + 上一个时间节点发生在他们身上的事

【你需要做的】

对每一个重要角色或势力，独立运行以下推导：

三步命运编织引擎（修订版）

第一步：世界暗流自转
→ 隔离主角，从各角色性格+资源处境自然推导出世界正在发生的事
→ 输出：N个并行的世界议程

第二步：主角生存轨迹  
→ 隔离世界，锁定主角此刻最深的需求或恐惧
→ 输出：主角当前最在意的东西，以及他为此愿意付出的代价上限

第三步：引力交汇（质量校验）
→ 寻找"资源焦点"——同时存在于世界议程和主角需求中的锚点
→ 校验：主角的介入是否被他最在意的东西逼出来的？
→ 校验：介入是否要求他违背某个本能或原则？
→ 如果两个校验都通过，碰撞成立
→ 如果校验失败，重新寻找焦点，或调整世界议程的某个细节

【输出格式】

{
  "world_tick_id": "时间节点标识",
  "independent_agendas": [
    {
      "character_or_faction": "角色/势力名称",
      "current_pressure": "此刻最紧迫的压力来源",
      "current_opportunity": "此刻看到的机会",
      "natural_action": "在没有主角存在的情况下，他自然会采取的行动",
      "action_ripple": "这个行动会对哪些人/势力产生什么波及"
    }
  ],
  "world_events_in_motion": [
    "此刻世界上正在发生的、与任何单一角色都无关的宏观事件（天灾、战争、政令等）"
  ]
}
```

然后，在World Tick输出完成之后，才进入第二个节点：

```
PROMPT · 主角遭遇节点（Protagonist Collision）

【输入】
- World Tick的输出（世界正在发生什么）
- 主角当前的位置、资源、状态

【你需要做的】

不是问"主角下一步要做什么"，
而是问：

"世界正在运转的这些事件和行动，
哪些会自然地与主角的路径产生交叉？
交叉的方式是：主动撞上、被动卷入、还是远远观察到了一个信号？"

主角是被世界裹挟进事件的，不是世界为主角制造事件的。
```

两个引擎的本质区别
三步命运编织引擎解决的是：这个事件为什么会发生？

World Tick：世界正在自转什么
